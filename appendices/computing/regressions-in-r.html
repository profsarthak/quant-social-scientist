Reading & Running Regressions in R

  • Show All Code
  • Hide All Code
  • View Source

The three-line workflow — lm(), summary(), broom::tidy() — and, more importantly, how to read what comes back: which numbers are the estimates, which are the uncertainty, and which ones people misread.

Fitting a regression in R is one line; the skill is reading the output. lm(y ~ x1 + x2, data) estimates the model, summary() prints the coefficient table, and broom::tidy() turns that table into a tidy data frame you can plot or filter. This entry is a reference for the output, not a theory of regression — the theory lives in Part III and the matrix algebra in OLS in matrix form. Here: what each column means, and how to show it honestly.

The model formula

R’s modelling verbs share one interface: the formula. y ~ x1 + x2 reads “y explained by x1 and x2”; the intercept is included automatically. A few idioms cover most needs: (McNulty 2021)

library(broom)

# fit: outcome ~ predictors, from a data frame
m <- lm(wage ~ educ + exper + female, data = survey)

# formula idioms
lm(y ~ x1 + x2,      data = d)   # additive
lm(y ~ x1 * x2,      data = d)   # x1, x2, and their interaction (x1:x2)
lm(y ~ poly(x, 2),   data = d)   # quadratic in x
lm(y ~ factor(grp),  data = d)   # categorical -> dummies, first level = baseline
lm(y ~ . - id,       data = d)   # every column except id

A categorical predictor becomes a set of indicator columns automatically; R holds one level out as the reference, and every other level’s coefficient is a contrast against that baseline — the single most common source of “why is my category missing?” confusion. (James et al. 2021)

Reading summary()

summary(m) prints the table everyone stares at. The columns, decoded: (McNulty 2021; Wooldridge 2019)

summary(m)
#> Coefficients:
#>              Estimate Std. Error t value Pr(>|t|)
#> (Intercept)   1.9421     0.2033    9.55  < 2e-16 ***
#> educ          0.4127     0.0158   26.12  < 2e-16 ***
#> exper         0.0051     0.0049    1.04  0.29863
#> female       -0.3311     0.0921   -3.60  0.00033 ***
#> Residual standard error: 1.41 on 996 degrees of freedom
#> Multiple R-squared: 0.318,  Adjusted R-squared: 0.316
#> F-statistic: 154.7 on 3 and 996 DF,  p-value: < 2.2e-16
  • Estimate — the fitted coefficient \hat\beta_j: the change in the outcome for a one-unit change in that predictor, holding the others fixed. The intercept is the fitted outcome when every predictor is zero.
  • Std. Error — the estimated standard deviation of that coefficient across hypothetical repeated samples; the ruler for how precisely it is pinned down. It is \sqrt{\hat\sigma^2\,[(X^\top X)^{-1}]_{jj}} from the matrix formula. (Wooldridge 2019)
  • t value = Estimate / Std. Error — how many standard errors the estimate sits from zero.
  • Pr(>|t|) — the two-sided p-value for H_0:\beta_j=0. The stars are a significance shorthand, not an importance ranking. (McNulty 2021)
  • Residual standard error — \hat\sigma, the typical size of a residual, in the outcome’s units.
  • R-squared / Adjusted — the share of outcome variance the model explains; adjusted penalises extra regressors so it can fall when you add a useless one. (James et al. 2021)
  • F-statistic — the joint test that all slopes are zero at once (the model-vs-intercept comparison).

Tidy output you can compute with

summary() prints; it does not return something you can plot. broom turns model objects into tidy data frames — the bridge from a fitted model back into the tidyverse workflow: (McNulty 2021)

tidy(m, conf.int = TRUE)   # one row per coefficient: estimate, std.error, statistic, p.value, conf.low/high
glance(m)                  # one row for the whole model: r.squared, adj.r.squared, sigma, statistic, AIC, BIC, nobs
augment(m)                 # original data + .fitted, .resid, .hat (leverage), .cooksd

tidy(..., conf.int = TRUE) is the one to remember: a coefficient plus its 95% interval, ready to plot. A coefficient plot — each estimate as a dot with its confidence interval as a whisker — communicates a model far better than a wall of stars, because it shows effect size and uncertainty together and lets a reader see at a glance which intervals clear zero. (Kaplan 2024)

Show the figure code 
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(5)
n = 600
educ   = rng.normal(13, 2.5, n)
exper  = rng.normal(0, 1.0, n)              # a near-null control: no real effect
female = rng.integers(0, 2, n).astype(float)
X = np.column_stack([np.ones(n), educ, exper, female])
beta_true = np.array([2.0, 0.40, 0.00, -0.33])  # exper's true coefficient is zero
y = X @ beta_true + rng.normal(0, 1.4, n)

# OLS by the normal equations = exactly what lm() computes
beta = np.linalg.solve(X.T @ X, X.T @ y)
resid = y - X @ beta
sigma2 = resid @ resid / (n - X.shape[1])
cov = sigma2 * np.linalg.inv(X.T @ X)
se = np.sqrt(np.diag(cov))
lo, hi = beta - 1.96 * se, beta + 1.96 * se

terms = ["(Intercept)", "educ", "exper", "female"]
ypos = np.arange(len(terms))[::-1]                 # intercept on top
# highlight the coefficients whose 95% interval clears zero
clears0 = (lo > 0) | (hi < 0)
colors = ["#e8531d" if c else "#8a8a7e" for c in clears0]

fig, ax = plt.subplots(figsize=(7.4, 3.8))
ax.axvline(0, color="#5e5e54", lw=1.2, ls=(0, (4, 3)))
for yi, b, l, h, c in zip(ypos, beta, lo, hi, colors):
    ax.plot([l, h], [yi, yi], color=c, lw=2.4, solid_capstyle="round")
    ax.plot(b, yi, "o", color=c, ms=7, markeredgecolor="#161613", markeredgewidth=1.0)
ax.set_yticks(ypos); ax.set_yticklabels(terms)
ax.set_xlabel("coefficient estimate  (95% CI)")
ax.set_title("Show the interval, not the stars")
ax.set_ylim(-0.6, len(terms) - 0.4)
fig.tight_layout()
plt.show()

Predictions and a first diagnostic look

predict(m, newdata = data.frame(educ = 16, exper = 10, female = 0),
        interval = "confidence")     # fitted value + CI for the mean
predict(m, newdata = nd, interval = "prediction")   # wider: CI for a new individual
plot(m)                              # 4 base diagnostic plots: residuals-vs-fitted, QQ, scale-location, leverage

The plot(m) panel is the quickest read on the assumptions: a curved residuals-vs-fitted plot flags functional-form problems; a fanning shape flags heteroskedasticity; the QQ plot checks residual normality; the leverage panel flags influential points (the .hat and .cooksd from augment()). (McNulty 2021)

Common pitfalls

WarningWhere R regression output gets misread

  • Reading stars as importance. *** means “precisely estimated as non-zero,” not “big” or “matters most.” A tiny, useless coefficient can be *** in a huge sample; a large, decision-relevant one can be n.s. in a small one. Report the estimate and its interval, not the star count. (McNulty 2021)

  • Forgetting the reference category. With factor(grp), the omitted level is folded into the intercept and every shown coefficient is a contrast against it. “Region B = 2.1” means relative to region A, not in absolute terms. Change the baseline with relevel() when a different comparison reads better. (James et al. 2021)

  • Default standard errors under heteroskedasticity. lm()/summary() report classical SEs that assume constant error variance. When that fails, the estimates are still fine but the SEs (and p-values) are wrong — use lmtest::coeftest(m, vcov = sandwich::vcovHC(m)) for robust errors. R will not warn you. (Wooldridge 2019)

  • Predicting outside the data’s range. predict() will happily extrapolate a fitted line far beyond where any data supported it; the interval widens but the model’s form was never tested out there.

  • Using a literal ```{r} chunk here. This is a Quarto note, not an R gotcha: in this encyclopedia the R is shown for reading, not executed (there is no R engine wired in), so R appears in plain ```r blocks. The one executable figure per entry is Python.

a curved residuals-vs-fitted plot flags [functional-form](../../content/03-regression/functional-form.qmd)
problems; a fanning shape flags [heteroskedasticity](../../content/03-regression/heteroskedasticity-and-gls.qmd);
the QQ plot checks residual normality; the leverage panel flags influential points (the `.hat` and `.cooksd`
from `augment()`). [@mcnulty_rmodeling]

## Common pitfalls

::: {.callout-warning title="Where R regression output gets misread"}

- **Reading stars as importance.** `***` means "precisely estimated as non-zero," not "big" or "matters most."
  A tiny, useless coefficient can be `***` in a huge sample; a large, decision-relevant one can be `n.s.` in a
  small one. Report the **estimate and its interval**, not the star count. [@mcnulty_rmodeling]

- **Forgetting the reference category.** With `factor(grp)`, the omitted level is folded into the intercept and
  every shown coefficient is a contrast against it. "Region B = 2.1" means *relative to region A*, not in
  absolute terms. Change the baseline with `relevel()` when a different comparison reads better. [@islr]

- **Default standard errors under heteroskedasticity.** `lm()`/`summary()` report classical SEs that assume
  constant error variance. When that fails, the estimates are still fine but the SEs (and $p$-values) are
  wrong — use `lmtest::coeftest(m, vcov = sandwich::vcovHC(m))` for
  [robust errors](../../content/03-regression/heteroskedasticity-and-gls.qmd). R will not warn you. [@wooldridge_intro]

- **Predicting outside the data's range.** `predict()` will happily extrapolate a fitted line far beyond where
  any data supported it; the interval widens but the model's *form* was never tested out there.

- **Using a literal `` ```{r} `` chunk here.** This is a Quarto note, not an R gotcha: in *this* encyclopedia
  the R is shown for reading, not executed (there is no R engine wired in), so R appears in plain ```` ```r ````
  blocks. The one executable figure per entry is Python.

:::

## From the sources {.unnumbered}

::: {.callout-note collapse="true" title="Who says what"}
- **McNulty, *Explanatory Statistical Modeling in R*** — the `lm()` → `summary()` → **broom** (`tidy`/`glance`/
  `augment`) workflow; decoding the coefficient table (estimate, SE, $t$, $p$, residual SE, $R^2$, $F$); the
  base `plot(m)` diagnostics; and the "explanatory, not predictive" framing of reading a fitted model.
- **James, Witten, Hastie & Tibshirani, *ISLR* (the R labs)** — the formula interface, factor/dummy handling
  and the reference level, interactions and `poly()`, and adjusted $R^2$.
- **Wooldridge, *Introductory Econometrics*** — the *interpretation* of each coefficient as a ceteris-paribus
  effect, the standard error as $\sqrt{\hat\sigma^2[(X^\top X)^{-1}]_{jj}}$, and the heteroskedasticity caveat
  on default SEs.
- **Kaplan, *Lessons in Statistical Thinking*** — the case for showing effects with confidence intervals
  (the coefficient plot) rather than significance stars.
:::
