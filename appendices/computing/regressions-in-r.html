Reading & Running Regressions in R

  • Show All Code
  • Hide All Code
  • View Source

Fitting a regression in R takes one line. Reading what comes back takes practice: which numbers are the estimates, which measure their uncertainty, and which ones people misread.

R fits a regression with a single command and prints a table. Most of the skill is in reading that table: each row is one predictor, the first number is its estimated effect, the second is how uncertain that estimate is, and the rest are ways of asking whether the effect could plausibly be zero. This page decodes the table, then shows how to turn it into a picture that tells the truth.

TipWhere you probably came from — and what you need

You likely arrived from multiple regression or inference for regression, wanting to see those ideas as software output, or from getting started in R. The question you came with is probably “I ran lm() and got a wall of numbers. Which ones matter?”

You need: the idea of a fitted line (an intercept and a slope) and of a standard error, from Part III; enough R to read name <- value and f(x), from getting started in R. You don’t need the matrix algebra. It lives in OLS in matrix form, and this page only points to it.

Jump to what you came for: the idea in words · a five-row regression, by hand · the model formula · reading summary() · tidy output and the coefficient plot · predictions and diagnostics

Why it matters

Almost every quantitative paper in the social sciences reports a regression table, and almost every one was produced by software like this. Misreading it is easy and common. People treat significance stars as a measure of importance, forget which category a dummy variable is being compared against, or trust standard errors that rest on an assumption the data break. Each of those mistakes is a misreading of one column (Reinhart 2015; Wooldridge 2019). Reading the output correctly is the step between knowing regression theory and using it.

The idea in words

Think of summary() as a report card with one row per predictor.

  • The estimate is the grade: the fitted slope. It says how much the outcome changes, on average, when that predictor goes up by one unit and the other predictors stay where they are (McNulty 2021).
  • The standard error is how much that grade would wobble if you collected a fresh sample and fitted the model again. Small means the estimate is pinned down; large means it is loose.
  • The t value and p-value both ask one question: is the estimate far enough from zero, measured in standard errors, that “no effect at all” looks implausible?
  • The lines at the bottom grade the model as a whole: how big a typical miss is, what share of the outcome’s variation the predictors account for, and whether the model beats having no predictors at all.

R produces the table in three steps. lm() fits the model and stores it as an object, summary() prints the table, and the broom package turns the same information into a data frame you can compute with or plot (Wickham et al. 2023).

A five-row regression, by hand

Before reading a real table, build a tiny one where every number can be checked with a calculator. Five students report hours studied and a quiz score out of 10 (this encyclopedia’s own toy data). Lines starting with #> show what R prints; the output is abridged, and every number in it was checked by hand.

d <- data.frame(hours = c(1, 2, 3, 4, 5),
                score = c(2, 4, 5, 4, 5))
m <- lm(score ~ hours, data = d)
summary(m)
#> Coefficients:
#>             Estimate Std. Error t value Pr(>|t|)
#> (Intercept)   2.2000     0.9381   2.345    0.101
#> hours         0.6000     0.2828   2.121    0.124
#>
#> Residual standard error: 0.8944 on 3 degrees of freedom
#> Multiple R-squared:    0.6,  Adjusted R-squared:  0.4667
#> F-statistic:   4.5 on 1 and 3 DF,  p-value: 0.124

Where each number comes from:

  1. Estimate, hours = 0.6. The average of the hours is 3 and of the scores is 4. Multiply each student’s distance from those averages and add up: (-2)(-2) + (-1)(0) + (0)(1) + (1)(0) + (2)(1) = 6. Divide by the sum of squared hour-distances, 4+1+0+1+4 = 10. The slope is 6/10 = 0.6: one more hour, 0.6 more points on average.
  2. Estimate, intercept = 2.2. The line passes through the two averages, so 4 - 0.6\times 3 = 2.2. That is the predicted score at zero hours.
  3. Residuals. The line predicts 2.8, 3.4, 4.0, 4.6, 5.2. The misses are -0.8, 0.6, 1.0, -0.6, -0.2, and their squares add up to 2.4.
  4. Residual standard error = 0.894. Divide 2.4 by the degrees of freedom: 5 data points minus 2 estimated numbers = 3. That gives 0.8, and \sqrt{0.8} = 0.894. A typical miss is just under one point.
  5. Std. Error, hours = 0.283. \sqrt{0.8 / 10}. More spread in hours (a bigger 10) would shrink it.
  6. t value = 2.121. 0.6 / 0.283: the slope is a bit over two standard errors from zero.
  7. Pr(>|t|) = 0.124. With only 3 degrees of freedom, a t value that large happens about 12% of the time even when the true slope is zero, so the slope is not significant at the 5% level. A 95% interval for it runs from about -0.30 to 1.50. Five students cannot pin down the effect of an hour of study.
  8. R-squared = 0.6. The scores vary by 6 in total (squared distances from 4: 4+0+1+0+1). The line leaves 2.4 of that unexplained, so it explains 1 - 2.4/6 = 0.6.
  9. F = 4.5. With a single predictor, the F-test asks the same question as the slope’s t-test, and F = t^2 = 2.121^2 = 4.5, with the same p-value.

Every regression table, however large, is built from these same pieces.

NoteJargon key — open if a term is unfamiliar
  • Model object — what lm() returns and you store under a name (m). It holds the estimates, residuals, fitted values and more; other functions (summary(), predict(), tidy()) read from it.
  • Formula — the y ~ x1 + x2 argument: outcome on the left of the ~ (“is explained by”), predictors on the right.
  • Coefficient / estimate — a fitted number in the model: the intercept or a slope, written \hat\beta_j.
  • Residual — an observed outcome minus the model’s fitted value for it: the miss.
  • Degrees of freedom — the number of observations minus the number of estimated coefficients.
  • Standard error — the estimated standard deviation of an estimate across repeated samples.
  • t value — estimate divided by its standard error.
  • p-value — the probability of a t value at least this far from zero if the true coefficient were zero.
  • R^2 — the share of the outcome’s variation the model accounts for, between 0 and 1.
  • F-statistic — a test that all the slopes are zero at once.
  • Reference level — for a categorical predictor, the category left out and absorbed into the intercept.
  • Tidy data frame — a table with one row per thing (per coefficient, per model, per observation) and one column per measurement; what broom produces.

The model formula

R’s modelling verbs share one interface: the formula. y ~ x1 + x2 reads “y explained by x1 and x2”; the intercept is included automatically. To estimate any model you need, at a minimum, a model function, some data and a formula (McNulty 2021). A few idioms cover most needs: (McNulty 2021; James et al. 2021)

library(broom)

# fit: outcome ~ predictors, from a data frame
m <- lm(wage ~ educ + exper + female, data = survey)

# formula idioms
lm(y ~ x1 + x2,      data = d)   # additive
lm(y ~ x1 * x2,      data = d)   # x1, x2, and their interaction (x1:x2)
lm(y ~ poly(x, 2),   data = d)   # quadratic in x
lm(y ~ factor(grp),  data = d)   # categorical -> dummies, first level = baseline
lm(y ~ . - id,       data = d)   # every column except id

In plain words: the formula is a sentence. ~ means “is explained by”, + means “and”, * means “and how they combine”, and . means “everything else in the data”.

A categorical predictor becomes a set of indicator columns automatically; R holds one level out as the reference, and every other level’s coefficient is a contrast against that baseline — the single most common source of “why is my category missing?” confusion. (James et al. 2021)

McNulty’s income example shows it in numbers. Regressing annual income on months of education and gender, with women (F) as the reference, gives an intercept of 15,513 and a genderM coefficient of 16,762. After relevel(ref = "M"), the intercept becomes 32,276 (that is, 15,513 + 16,762) and the coefficient becomes genderF = −16,762. The education slope (269.8) does not move. Nothing about the data or the fit changed, only which group the intercept describes (McNulty 2021).

Reading summary()

summary(m) prints the table everyone stares at. Here is a real one: McNulty’s model of students’ final-year exam scores on their scores in years 1, 2 and 3, fitted to 975 students (McNulty 2021).

summary(full_model)
#> lm(formula = Final ~ Yr1 + Yr2 + Yr3, data = ugtests)
#> Coefficients:
#>             Estimate Std. Error t value Pr(>|t|)
#> (Intercept) 14.14599    5.48006   2.581  0.00999 **
#> Yr1          0.07603    0.06538   1.163  0.24519
#> Yr2          0.43129    0.03251  13.267  < 2e-16 ***
#> Yr3          0.86568    0.02914  29.710  < 2e-16 ***
#> Residual standard error: 30.43 on 971 degrees of freedom
#> Multiple R-squared:  0.5303,  Adjusted R-squared:  0.5289
#> F-statistic: 365.5 on 3 and 971 DF,  p-value: < 2.2e-16

The columns, decoded: (McNulty 2021; Wooldridge 2019)

  • Estimate — the fitted coefficient \hat\beta_j: the change in the outcome for a one-unit change in that predictor, holding the others fixed. The intercept is the fitted outcome when every predictor is zero. Here: among students with the same year-1 and year-2 scores, one more point in year 3 goes with about 0.87 more points in the final year.

  • Std. Error — the estimated standard deviation of that coefficient across hypothetical repeated samples; the ruler for how precisely it is pinned down. It is \sqrt{\hat\sigma^2\,[(X^\top X)^{-1}]_{jj}} from the matrix formula. (Wooldridge 2019)

    In plain words: the typical size of a miss (\hat\sigma), scaled by how much independent spread that predictor has. In the five-row example this was \sqrt{0.8/10}.

  • t value = Estimate / Std. Error — how many standard errors the estimate sits from zero. Check one: 0.86568 / 0.02914 = 29.7.

  • Pr(>|t|) — the two-sided p-value for H_0:\beta_j=0. The stars are a significance shorthand, not an importance ranking. Yr1 has p = 0.245: with years 2 and 3 already in the model, year 1 adds no detectable association. McNulty’s 95% interval for it, from confint(), runs from −0.05 to 0.20 and crosses zero.

  • Residual standard error — \hat\sigma, the typical size of a residual, in the outcome’s units: about 30 exam points here.

  • R-squared / Adjusted — the share of outcome variance the model explains; adjusted penalises extra regressors so it can fall when you add a useless one. (James et al. 2021) Dropping Yr1 moves R^2 only from 0.5303 to 0.5297 (McNulty 2021).

  • F-statistic — the joint test that all slopes are zero at once (the model-vs-intercept comparison). A high R^2 on a handful of observations can still fail it, and a low R^2 on a large dataset can pass (McNulty 2021).

Tidy output you can compute with

summary() prints; it does not return something you can plot. broom turns model objects into tidy data frames — the bridge from a fitted model back into the tidyverse workflow. It has three general tools: glance() gives one row per model, tidy() one row per coefficient, and augment() one row per observation of the data, with residuals and influence statistics added (Wickham et al. 2023). Dayal uses tidy() the same way, to turn a table of robust-standard-error results into a formatted table for a report (Dayal 2020).

tidy(m, conf.int = TRUE)   # one row per coefficient: estimate, std.error, statistic, p.value, conf.low/high
glance(m)                  # one row for the whole model: r.squared, adj.r.squared, sigma, statistic, AIC, BIC, nobs
augment(m)                 # original data + .fitted, .resid, .hat (leverage), .cooksd

tidy(..., conf.int = TRUE) is the one to remember: a coefficient plus its 95% interval, ready to plot. A coefficient plot — each estimate as a dot with its confidence interval as a whisker — communicates a model far better than a wall of stars, because it shows effect size and uncertainty together and lets a reader see at a glance which intervals clear zero. (Kaplan 2024) A p-value says nothing about how big an effect is; a confidence interval carries far more information (Reinhart 2015).

Show the figure code 
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(5)
n = 600
educ   = rng.normal(13, 2.5, n)
exper  = rng.normal(0, 1.0, n)              # a near-null control: no real effect
female = rng.integers(0, 2, n).astype(float)
X = np.column_stack([np.ones(n), educ, exper, female])
beta_true = np.array([2.0, 0.40, 0.00, -0.33])  # exper's true coefficient is zero
y = X @ beta_true + rng.normal(0, 1.4, n)

# OLS by the normal equations = exactly what lm() computes
beta = np.linalg.solve(X.T @ X, X.T @ y)
resid = y - X @ beta
sigma2 = resid @ resid / (n - X.shape[1])
cov = sigma2 * np.linalg.inv(X.T @ X)
se = np.sqrt(np.diag(cov))
lo, hi = beta - 1.96 * se, beta + 1.96 * se

terms = ["(Intercept)", "educ", "exper", "female"]
ypos = np.arange(len(terms))[::-1]                 # intercept on top
# highlight the coefficients whose 95% interval clears zero
clears0 = (lo > 0) | (hi < 0)
colors = ["#e8531d" if c else "#8a8a7e" for c in clears0]

fig, ax = plt.subplots(figsize=(7.4, 3.8))
ax.axvline(0, color="#5e5e54", lw=1.2, ls=(0, (4, 3)))
for yi, b, l, h, c in zip(ypos, beta, lo, hi, colors):
    ax.plot([l, h], [yi, yi], color=c, lw=2.4, solid_capstyle="round")
    ax.plot(b, yi, "o", color=c, ms=7, markeredgecolor="#161613", markeredgewidth=1.0)
ax.set_yticks(ypos); ax.set_yticklabels(terms)
ax.set_xlabel("coefficient estimate  (95% CI)")
ax.set_title("Show the interval, not the stars")
ax.set_ylim(-0.6, len(terms) - 0.4)
fig.tight_layout()
plt.show()

Predictions and a first diagnostic look

predict(m, newdata = data.frame(educ = 16, exper = 10, female = 0),
        interval = "confidence")     # fitted value + CI for the mean
predict(m, newdata = nd, interval = "prediction")   # wider: CI for a new individual
plot(m)                              # 4 base diagnostic plots: residuals-vs-fitted, QQ, scale-location, leverage

The two intervals answer different questions. ISLR’s lab shows the gap: predicting median house value at lstat = 10, the confidence interval for the average is (24.47, 25.63) and the prediction interval for a single new neighbourhood is (12.83, 37.28). Both are centred on the same fitted value, 25.05, but the second also has to allow for one observation’s own scatter (James et al. 2021).

The plot(m) panel is the quickest read on the assumptions (ISLR’s lab draws all four at once with par(mfrow = c(2, 2))) (James et al. 2021): a curved residuals-vs-fitted plot flags functional-form problems; a fanning shape flags heteroskedasticity; the QQ plot checks residual normality; the leverage panel flags influential points (the .hat and .cooksd from augment()). McNulty’s list of things to check before trusting the coefficients is the same: highly correlated predictors, non-linear relationships the residuals reveal, and unusual observations (outliers in the outcome, high-leverage points in the inputs) (McNulty 2021).

Common pitfalls

WarningWhere R regression output gets misread

  • Reading stars as importance. *** means “precisely estimated as non-zero,” not “big” or “matters most.” A tiny, useless coefficient can be *** in a huge sample; a large, decision-relevant one can be n.s. in a small one, as the five-row example’s slope was. Report the estimate and its interval, not the star count. (Reinhart 2015)

  • Dropping every non-significant predictor. McNulty advises removing non-significant variables for a simpler model (McNulty 2021), and for description that is reasonable. When the goal is a causal estimate, a control belongs in the model because of what it blocks, not because of its own p-value. See what regression can and can’t tell you.

  • Forgetting the reference category. With factor(grp), the omitted level is folded into the intercept and every shown coefficient is a contrast against it. “Region B = 2.1” means relative to region A, not in absolute terms. Change the baseline with relevel() when a different comparison reads better. (James et al. 2021)

  • Default standard errors under heteroskedasticity. lm()/summary() report classical SEs that assume constant error variance. When that fails, the estimates are still fine but the SEs (and p-values) are wrong — use lmtest::coeftest(m, vcov = sandwich::vcovHC(m)) for robust errors. R will not warn you. (Wooldridge 2019) Dayal’s worked examples do exactly this before tabulating with tidy() (Dayal 2020).

  • Predicting outside the data’s range. predict() will happily extrapolate a fitted line far beyond where any data supported it; the interval widens but the model’s form was never tested out there.

  • Using a literal ```{r} chunk here. This is a Quarto note, not an R gotcha: in this encyclopedia the R is shown for reading, not executed (there is no R engine wired in), so R appears in plain ```r blocks. The one executable figure per entry is Python.

R fits a regression with a single command and prints a table. Most of the skill is in reading that table:
each row is one predictor, the first number is its estimated effect, the second is how uncertain that

the table, then shows how to turn it into a picture that tells the truth.

## Why it matters

Almost every quantitative paper in the social sciences reports a regression table, and almost every one was
produced by software like this. Misreading it is easy and common. People treat significance stars as a
measure of importance, forget which category a dummy variable is being compared against, or trust standard
errors that rest on an assumption the data break. Each of those mistakes is a misreading of one column
[@reinhart_swrong; @wooldridge_intro]. Reading the output correctly is the step between knowing regression
theory and using it.

## The idea in words {#sec-idea}

Think of `summary()` as a report card with one row per predictor.

- **The estimate** is the grade: the fitted slope. It says how much the outcome changes, on average, when
  that predictor goes up by one unit and the other predictors stay where they are [@mcnulty_rmodeling].
- **The standard error** is how much that grade would wobble if you collected a fresh sample and fitted the
  model again. Small means the estimate is pinned down; large means it is loose.
- **The t value and p-value** both ask one question: is the estimate far enough from zero, measured in
  standard errors, that "no effect at all" looks implausible?
- **The lines at the bottom** grade the model as a whole: how big a typical miss is, what share of the
  outcome's variation the predictors account for, and whether the model beats having no predictors at all.

R produces the table in three steps. `lm()` fits the model and stores it as an object, `summary()` prints
the table, and the **broom** package turns the same information into a data frame you can compute with or
plot [@wickham_r4ds].

## A five-row regression, by hand {#sec-by-hand}

Before reading a real table, build a tiny one where every number can be checked with a calculator. Five
students report hours studied and a quiz score out of 10 (this encyclopedia's own toy data). Lines starting
with `#>` show what R prints; the output is abridged, and every number in it was checked by hand.

```r
d <- data.frame(hours = c(1, 2, 3, 4, 5),
                score = c(2, 4, 5, 4, 5))
m <- lm(score ~ hours, data = d)
summary(m)
#> Coefficients:
#>             Estimate Std. Error t value Pr(>|t|)
#> (Intercept)   2.2000     0.9381   2.345    0.101
#> hours         0.6000     0.2828   2.121    0.124
#>
#> Residual standard error: 0.8944 on 3 degrees of freedom
#> Multiple R-squared:    0.6,  Adjusted R-squared:  0.4667
#> F-statistic:   4.5 on 1 and 3 DF,  p-value: 0.124
```

Where each number comes from:

1. **Estimate, `hours` = 0.6.** The average of the hours is 3 and of the scores is 4. Multiply each
   student's distance from those averages and add up: $(-2)(-2) + (-1)(0) + (0)(1) + (1)(0) + (2)(1) = 6$.
   Divide by the sum of squared hour-distances, $4+1+0+1+4 = 10$. The slope is $6/10 = 0.6$: one more hour,
   0.6 more points on average.
2. **Estimate, intercept = 2.2.** The line passes through the two averages, so $4 - 0.6\times 3 = 2.2$. That
   is the predicted score at zero hours.
3. **Residuals.** The line predicts 2.8, 3.4, 4.0, 4.6, 5.2. The misses are $-0.8, 0.6, 1.0, -0.6, -0.2$, and
   their squares add up to 2.4.
4. **Residual standard error = 0.894.** Divide 2.4 by the **degrees of freedom**: 5 data points minus 2
   estimated numbers = 3. That gives 0.8, and $\sqrt{0.8} = 0.894$. A typical miss is just under one point.
5. **Std. Error, `hours` = 0.283.** $\sqrt{0.8 / 10}$. More spread in hours (a bigger 10) would shrink it.
6. **t value = 2.121.** $0.6 / 0.283$: the slope is a bit over two standard errors from zero.
7. **Pr(>|t|) = 0.124.** With only 3 degrees of freedom, a t value that large happens about 12% of the time
   even when the true slope is zero, so the slope is not significant at the 5% level. A 95% interval for it
   runs from about $-0.30$ to $1.50$. Five students cannot pin down the effect of an hour of study.
8. **R-squared = 0.6.** The scores vary by 6 in total (squared distances from 4: $4+0+1+0+1$). The line
   leaves 2.4 of that unexplained, so it explains $1 - 2.4/6 = 0.6$.
9. **F = 4.5.** With a single predictor, the F-test asks the same question as the slope's t-test, and
   $F = t^2 = 2.121^2 = 4.5$, with the same p-value.

Every regression table, however large, is built from these same pieces.

::: {.callout-note collapse="true" title="Jargon key — open if a term is unfamiliar"}
- **Model object** — what `lm()` returns and you store under a name (`m`). It holds the estimates,
  residuals, fitted values and more; other functions (`summary()`, `predict()`, `tidy()`) read from it.
- **Formula** — the `y ~ x1 + x2` argument: outcome on the left of the `~` ("is explained by"), predictors on
  the right.
- **Coefficient / estimate** — a fitted number in the model: the intercept or a slope, written $\hat\beta_j$.
- **Residual** — an observed outcome minus the model's fitted value for it: the miss.
- **Degrees of freedom** — the number of observations minus the number of estimated coefficients.
- **Standard error** — the estimated standard deviation of an estimate across repeated samples.
- **t value** — estimate divided by its standard error.
- **p-value** — the probability of a t value at least this far from zero if the true coefficient were zero.
- **$R^2$** — the share of the outcome's variation the model accounts for, between 0 and 1.
- **F-statistic** — a test that all the slopes are zero at once.
- **Reference level** — for a categorical predictor, the category left out and absorbed into the intercept.
- **Tidy data frame** — a table with one row per thing (per coefficient, per model, per observation) and
  one column per measurement; what broom produces.
:::

## The model formula {#sec-formula}

R's modelling verbs share one interface: the **formula**. `y ~ x1 + x2` reads "`y` explained by `x1` and
`x2`"; the intercept is included automatically. To estimate any model you need, at a minimum, a model
function, some data and a formula [@mcnulty_rmodeling]. A few idioms cover most needs: [@mcnulty_rmodeling; @islr]

```r
library(broom)

# fit: outcome ~ predictors, from a data frame
m <- lm(wage ~ educ + exper + female, data = survey)

# formula idioms
lm(y ~ x1 + x2,      data = d)   # additive
lm(y ~ x1 * x2,      data = d)   # x1, x2, and their interaction (x1:x2)
lm(y ~ poly(x, 2),   data = d)   # quadratic in x
lm(y ~ factor(grp),  data = d)   # categorical -> dummies, first level = baseline
lm(y ~ . - id,       data = d)   # every column except id
```

> **In plain words:** the formula is a sentence. `~` means "is explained by", `+` means "and", `*` means
> "and how they combine", and `.` means "everything else in the data".

A **categorical** predictor becomes a set of indicator columns automatically; R holds one level out as the
**reference**, and every other level's coefficient is a contrast *against that baseline* — the single most
common source of "why is my category missing?" confusion. [@islr]

McNulty's income example shows it in numbers. Regressing annual income on months of education and gender,
with women (`F`) as the reference, gives an intercept of 15,513 and a `genderM` coefficient of 16,762. After
`relevel(ref = "M")`, the intercept becomes 32,276 (that is, 15,513 + 16,762) and the coefficient becomes
`genderF` = −16,762. The education slope (269.8) does not move. Nothing about the data or the fit changed,
only which group the intercept describes [@mcnulty_rmodeling].

## Reading `summary()` {#sec-summary}

`summary(m)` prints the table everyone stares at. Here is a real one: McNulty's model of students' final-year
exam scores on their scores in years 1, 2 and 3, fitted to 975 students [@mcnulty_rmodeling].

```r
summary(full_model)
#> lm(formula = Final ~ Yr1 + Yr2 + Yr3, data = ugtests)
#> Coefficients:
#>             Estimate Std. Error t value Pr(>|t|)
#> (Intercept) 14.14599    5.48006   2.581  0.00999 **
#> Yr1          0.07603    0.06538   1.163  0.24519
#> Yr2          0.43129    0.03251  13.267  < 2e-16 ***
#> Yr3          0.86568    0.02914  29.710  < 2e-16 ***
#> Residual standard error: 30.43 on 971 degrees of freedom
#> Multiple R-squared:  0.5303,  Adjusted R-squared:  0.5289
#> F-statistic: 365.5 on 3 and 971 DF,  p-value: < 2.2e-16
```

The columns, decoded: [@mcnulty_rmodeling; @wooldridge_intro]

- **Estimate** — the fitted coefficient $\hat\beta_j$: the change in the outcome for a one-unit change in that
  predictor, *holding the others fixed*. The intercept is the fitted outcome when every predictor is zero.
  Here: among students with the same year-1 and year-2 scores, one more point in year 3 goes with about 0.87
  more points in the final year.
- **Std. Error** — the estimated standard deviation of that coefficient across hypothetical repeated samples;
  the ruler for how precisely it is pinned down. It is $\sqrt{\hat\sigma^2\,[(X^\top X)^{-1}]_{jj}}$ from the
  [matrix formula](../math/ols-in-matrix-form.qmd). [@wooldridge_intro]

  > **In plain words:** the typical size of a miss ($\hat\sigma$), scaled by how much independent spread
  > that predictor has. In the five-row example this was $\sqrt{0.8/10}$.

- **t value** = Estimate / Std. Error — how many standard errors the estimate sits from zero. Check one:
  $0.86568 / 0.02914 = 29.7$.
- **Pr(>|t|)** — the two-sided $p$-value for $H_0:\beta_j=0$. The stars are a significance shorthand, **not** an
  importance ranking. `Yr1` has $p = 0.245$: with years 2 and 3 already in the model, year 1 adds no detectable
  association. McNulty's 95% interval for it, from `confint()`, runs from −0.05 to 0.20 and crosses zero.
- **Residual standard error** — $\hat\sigma$, the typical size of a residual, in the outcome's units: about 30
  exam points here.
- **R-squared / Adjusted** — the share of outcome variance the model explains; *adjusted* penalises extra
  regressors so it can fall when you add a useless one. [@islr] Dropping `Yr1` moves $R^2$ only from 0.5303 to
  0.5297 [@mcnulty_rmodeling].
- **F-statistic** — the joint test that *all* slopes are zero at once (the model-vs-intercept comparison). A
  high $R^2$ on a handful of observations can still fail it, and a low $R^2$ on a large dataset can pass
  [@mcnulty_rmodeling].

## Tidy output you can compute with {#sec-tidy}

`summary()` prints; it does not return something you can plot. **broom** turns model objects into tidy data
frames — the bridge from a fitted model back into the [tidyverse workflow](../../content/dataframes/index.qmd).
It has three general tools: `glance()` gives one row per model, `tidy()` one row per coefficient, and
`augment()` one row per observation of the data, with residuals and influence statistics added
[@wickham_r4ds]. Dayal uses `tidy()` the same way, to turn a table of robust-standard-error results into a
formatted table for a report [@dayal_r_datascience].

```r
tidy(m, conf.int = TRUE)   # one row per coefficient: estimate, std.error, statistic, p.value, conf.low/high
glance(m)                  # one row for the whole model: r.squared, adj.r.squared, sigma, statistic, AIC, BIC, nobs
augment(m)                 # original data + .fitted, .resid, .hat (leverage), .cooksd
```

`tidy(..., conf.int = TRUE)` is the one to remember: a coefficient plus its 95% interval, ready to plot. A
**coefficient plot** — each estimate as a dot with its confidence interval as a whisker — communicates a model
far better than a wall of stars, because it shows *effect size and uncertainty together* and lets a reader see
at a glance which intervals clear zero. [@kaplan_lessons] A $p$-value says nothing about how big an effect is;
a confidence interval carries far more information [@reinhart_swrong].

```{python}
#| label: fig-coef-plot
#| fig-cap: "A coefficient plot — the honest way to show a regression. Each dot is an estimate; each whisker its 95% confidence interval; the dashed line is zero (no effect). An interval that crosses zero is 'not significant' — but the plot shows the whole story a p-value hides: the effect's size, its sign, and how precisely it is pinned down. Here the estimates and standard errors are computed by hand from the normal equations (the same numbers lm()/broom::tidy() would return); only the drawing is Python. This is the shape broom::tidy(m, conf.int = TRUE) |> ggplot(aes(estimate, term)) + geom_pointrange() produces in R."
#| code-fold: true
#| code-summary: "Show the figure code"

import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(5)
n = 600
educ   = rng.normal(13, 2.5, n)
exper  = rng.normal(0, 1.0, n)              # a near-null control: no real effect
female = rng.integers(0, 2, n).astype(float)
X = np.column_stack([np.ones(n), educ, exper, female])
beta_true = np.array([2.0, 0.40, 0.00, -0.33])  # exper's true coefficient is zero
y = X @ beta_true + rng.normal(0, 1.4, n)

# OLS by the normal equations = exactly what lm() computes
beta = np.linalg.solve(X.T @ X, X.T @ y)
resid = y - X @ beta
sigma2 = resid @ resid / (n - X.shape[1])
cov = sigma2 * np.linalg.inv(X.T @ X)
se = np.sqrt(np.diag(cov))
lo, hi = beta - 1.96 * se, beta + 1.96 * se

terms = ["(Intercept)", "educ", "exper", "female"]
ypos = np.arange(len(terms))[::-1]                 # intercept on top
# highlight the coefficients whose 95% interval clears zero
clears0 = (lo > 0) | (hi < 0)
colors = ["#e8531d" if c else "#8a8a7e" for c in clears0]

fig, ax = plt.subplots(figsize=(7.4, 3.8))
ax.axvline(0, color="#5e5e54", lw=1.2, ls=(0, (4, 3)))
for yi, b, l, h, c in zip(ypos, beta, lo, hi, colors):
    ax.plot([l, h], [yi, yi], color=c, lw=2.4, solid_capstyle="round")
    ax.plot(b, yi, "o", color=c, ms=7, markeredgecolor="#161613", markeredgewidth=1.0)
ax.set_yticks(ypos); ax.set_yticklabels(terms)
ax.set_xlabel("coefficient estimate  (95% CI)")
ax.set_title("Show the interval, not the stars")
ax.set_ylim(-0.6, len(terms) - 0.4)
fig.tight_layout()
plt.show()
```

## Predictions and a first diagnostic look {#sec-predict}

```r
predict(m, newdata = data.frame(educ = 16, exper = 10, female = 0),
        interval = "confidence")     # fitted value + CI for the mean
predict(m, newdata = nd, interval = "prediction")   # wider: CI for a new individual
plot(m)                              # 4 base diagnostic plots: residuals-vs-fitted, QQ, scale-location, leverage
```

The two intervals answer different questions. ISLR's lab shows the gap: predicting median house value at
`lstat = 10`, the confidence interval for the *average* is (24.47, 25.63) and the prediction interval for a
*single* new neighbourhood is (12.83, 37.28). Both are centred on the same fitted value, 25.05, but the second
also has to allow for one observation's own scatter [@islr].

The `plot(m)` panel is the quickest read on the [assumptions](../../content/03-regression/gauss-markov-assumptions.qmd)
(ISLR's lab draws all four at once with `par(mfrow = c(2, 2))`) [@islr]:
a curved residuals-vs-fitted plot flags [functional-form](../../content/03-regression/functional-form.qmd)
problems; a fanning shape flags [heteroskedasticity](../../content/03-regression/heteroskedasticity-and-gls.qmd);
the QQ plot checks residual normality; the leverage panel flags influential points (the `.hat` and `.cooksd`
from `augment()`). McNulty's list of things to check before trusting the coefficients is the same:
highly correlated predictors, non-linear relationships the residuals reveal, and unusual observations
(outliers in the outcome, high-leverage points in the inputs) [@mcnulty_rmodeling].

## Common pitfalls

::: {.callout-warning title="Where R regression output gets misread"}

- **Reading stars as importance.** `***` means "precisely estimated as non-zero," not "big" or "matters most."
  A tiny, useless coefficient can be `***` in a huge sample; a large, decision-relevant one can be `n.s.` in a
  small one, as the five-row example's slope was. Report the **estimate and its interval**, not the star
  count. [@reinhart_swrong]

- **Dropping every non-significant predictor.** McNulty advises removing non-significant variables for a
  simpler model [@mcnulty_rmodeling], and for description that is reasonable. When the goal is a causal
  estimate, a control belongs in the model because of what it blocks, not because of its own p-value. See
  [what regression can and can't tell you](../../content/03-regression/regression-and-causality.qmd).

- **Forgetting the reference category.** With `factor(grp)`, the omitted level is folded into the intercept and
  every shown coefficient is a contrast against it. "Region B = 2.1" means *relative to region A*, not in
  absolute terms. Change the baseline with `relevel()` when a different comparison reads better. [@islr]

- **Default standard errors under heteroskedasticity.** `lm()`/`summary()` report classical SEs that assume
  constant error variance. When that fails, the estimates are still fine but the SEs (and $p$-values) are
  wrong — use `lmtest::coeftest(m, vcov = sandwich::vcovHC(m))` for
  [robust errors](../../content/03-regression/heteroskedasticity-and-gls.qmd). R will not warn you.
  [@wooldridge_intro] Dayal's worked examples do exactly this before tabulating with `tidy()`
  [@dayal_r_datascience].

- **Predicting outside the data's range.** `predict()` will happily extrapolate a fitted line far beyond where
  any data supported it; the interval widens but the model's *form* was never tested out there.

- **Using a literal `` ```{r} `` chunk here.** This is a Quarto note, not an R gotcha: in *this* encyclopedia
  the R is shown for reading, not executed (there is no R engine wired in), so R appears in plain ```` ```r ````
  blocks. The one executable figure per entry is Python.

:::
