Getting Started in R

  • Show All Code
  • Hide All Code
  • View Source

The working subset of R for social science — vectors, data frames, the pipe, and functions — enough of the language to be productive fast, without the tutorial detours.

R rewards a small amount of the right knowledge. You do not need the whole language; you need to think in vectors, keep your data in a data frame, chain steps with the pipe, and wrap anything you repeat in a function. Those four ideas carry most applied work. This is the on-ramp — the language itself; the tidyverse wrangling verbs and reading a regression build on top of it.

R thinks in vectors

The single most important habit: R operates on whole vectors at once, not element by element. A vector is made with c(), and arithmetic is vectorised — it applies to every element without a loop. (Kaplan 2024)

x <- c(4, 8, 15, 16, 23, 42)   # a numeric vector;  <- is assignment
x * 2                          # 8 16 30 32 46 84   — no loop needed
mean(x); sd(x); length(x)      # summaries take the whole vector
x[x > 15]                      # 16 23 42            — logical subsetting

Writing a for loop where a vectorised expression would do is the most common beginner’s tell; R is faster and clearer when you let the vector operation speak. The main atomic types are numeric, character ("text"), logical (TRUE/FALSE), and factor (categorical — a character with a fixed set of levels, which is how R encodes groups for models). (McNulty 2021)

Keep your data in a data frame

A data frame (or its modern form, the tibble) is R’s table: named columns that can hold different types, all the same length — one row per observation, one column per variable. It is the object every modelling and plotting verb expects. (Dayal 2020)

d <- data.frame(
  name = c("Ann", "Ben", "Cy"),
  age  = c(31, 25, 40),
  group = factor(c("T", "C", "T"))
)
d$age            # a column, by name ($)
d[d$group == "T", ]   # rows where group is T, all columns
nrow(d); names(d)     # dimensions and column names

Load real data with the readr package (read_csv("file.csv")); everything downstream assumes it arrived as a tidy data frame. (Llaudet and Imai 2022)

The pipe, and writing functions

The pipe |> passes the thing on its left as the first argument of the function on its right, so a sequence of steps reads top-to-bottom instead of inside-out: (Kaplan 2024)

# nested (hard to read)           # piped (reads as steps)
round(mean(x, na.rm = TRUE), 2)   x |> mean(na.rm = TRUE) |> round(2)

And when you find yourself copying a block of code with one thing changed, make it a function:

z_score <- function(v) {          # v is the argument
  (v - mean(v)) / sd(v)           # last expression is returned
}
z_score(x)

Functions plus vectorisation are the whole game: express the operation once, apply it to any vector.

Compute, then look — always

The reason social scientists learn to simulate and plot, not just compute summaries, is that summaries hide shape. Anscombe’s quartet is the classic demonstration, and it is a one-line lesson worth internalising before any modelling. (Dayal 2015)

Show the figure code 
import numpy as np
import matplotlib.pyplot as plt

x123 = np.array([10, 8, 13, 9, 11, 14, 6, 4, 12, 7, 5])
data = {
    "I":   (x123, np.array([8.04,6.95,7.58,8.81,8.33,9.96,7.24,4.26,10.84,4.82,5.68])),
    "II":  (x123, np.array([9.14,8.14,8.74,8.77,9.26,8.10,6.13,3.10,9.13,7.26,4.74])),
    "III": (x123, np.array([7.46,6.77,12.74,7.11,7.81,8.84,6.08,5.39,8.15,6.42,5.73])),
    "IV":  (np.array([8,8,8,8,8,8,8,19,8,8,8]),
            np.array([6.58,5.76,7.71,8.84,8.47,7.04,5.25,12.50,5.56,7.91,6.89])),
}
xs = np.linspace(3, 20, 50)

fig, axes = plt.subplots(2, 2, figsize=(7.8, 5.4), sharex=True, sharey=True)
for ax, (name, (x, y)) in zip(axes.flat, data.items()):
    b1 = np.cov(x, y, bias=True)[0, 1] / np.var(x)     # slope, by hand
    b0 = y.mean() - b1 * x.mean()
    r = np.corrcoef(x, y)[0, 1]
    ax.plot(xs, b0 + b1 * xs, color="#e8531d", lw=2.0, zorder=1)
    ax.scatter(x, y, s=28, color="#161613", zorder=2, edgecolor="#f4f3ec", linewidth=0.6)
    ax.set_title(f"Set {name}:  r = {r:.2f},  ŷ = {b0:.1f} + {b1:.2f}x", fontsize=9)
    ax.set_xlim(2, 20); ax.set_ylim(2, 14)
fig.suptitle("Same statistics, four different realities — so plot the data", fontsize=11)
fig.tight_layout()
plt.show()

Common pitfalls

WarningWhere new R users trip

  • Looping instead of vectorising. for (i in 1:length(x)) x[i] <- x[i]*2 is slow and un-R; write x * 2. Reach for a loop only when each step truly depends on the last. (Kaplan 2024)

  • Confusing <-, =, and ==. <- assigns, == tests equality, and a single = assigns inside a function call (an argument). Mixing them up produces silent surprises, not errors.

  • NA propagates. Any arithmetic touching a missing value returns NA. mean(x) on a vector with one NA is NA — you must ask for mean(x, na.rm = TRUE). R makes you acknowledge missingness on purpose.

  • Recycling. Operating on vectors of different lengths silently recycles the shorter one. c(1,2,3,4) + c(0,10) gives 1 12 3 14, not an error — occasionally handy, often a bug.

  • Factor surprises. A grouping variable read as text may need factor(); and a factor’s reference level (the one folded into the intercept) is the first alphabetically unless you set it — the source of “why is my category missing from the regression?” (McNulty 2021)
