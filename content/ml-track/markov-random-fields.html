Markov Random Fields

  • Show All Code
  • Hide All Code
  • View Source

Graphical models without arrows. When neighbours simply go together (pixels, friends, survey items), draw an undirected edge, score how well each local pattern fits, and let one normalising constant turn the scores into probabilities.

A Markov random field (MRF), or undirected graphical model, describes variables that depend on their neighbours without saying which one comes first. Two variables with no edge between them are independent given everything else, and a variable’s neighbours are all you need to know to predict it. The joint distribution is a product of local compatibility scores divided by a partition function Z. That one constant makes MRFs natural to write down and expensive to fit. The Ising model, Gaussian graphical models and conditional random fields are all MRFs.

Why it matters

A DAG asks you to point every arrow. For causal questions that is the point. For some data it is awkward. Murphy’s example is an image: neighbouring pixels have similar intensities, but no pixel causes its neighbour (Murphy 2012). You can force a 2-D grid into a DAG (a “Markov mesh”), but the conditional independences come out unnatural. In Murphy’s 20-node lattice the set of nodes that shields the middle node X_8 from everything else is six nodes, its parents, children and co-parents (3, 4, 7, 9, 12, 13), not the four nearest neighbours you would expect (Murphy 2012). Drop the arrows and that set becomes the four neighbours.

Murphy lists the trade-off plainly. Undirected models are symmetric, which suits spatial and relational data, and their conditional versions (CRFs) make better discriminative sequence models than directed ones. Against that, their parameters are less interpretable and less modular, and fitting them is more expensive (Murphy 2012). You have met MRFs already in this encyclopedia, under other names: the psychometric networks of the measurement entry are Gaussian MRFs, the image-denoising showcase in variational inference is an Ising model, and the raking used to calibrate survey weights is the classic algorithm for fitting a tabular MRF. This entry is the common machinery behind all three.

Separation means independence

Conditional independence is simpler to read off an undirected graph than off a DAG. Take three sets of nodes A, B and C. If deleting C leaves no path from A to B, then A is independent of B given C. Murphy calls this the global Markov property (Murphy 2012). Two weaker readings follow from it:

  • Local: a node’s Markov blanket, the set that makes it independent of everything else, is just its immediate neighbours (Murphy 2012).
  • Pairwise: two nodes with no edge between them are independent given all the rest (Murphy 2012).

Global implies local implies pairwise. The surprising part is that, as long as every configuration has positive probability, pairwise also implies global, so the three readings coincide (Murphy 2012). That matters in practice. Pairwise statements are the easiest to check in data, and they are enough to build a graph from which every other independence can be read (Murphy 2012). This is how a psychometric network is built: estimate which pairs of items are independent given all the others, and leave those edges out.

Undirected and directed graphs say different things

You cannot turn a DAG into an undirected graph by deleting the arrowheads. A collider A\to C\leftarrow B says A and B are independent but become dependent once you condition on C (the collider bias of the causal track). The chain A - C - B says the opposite: dependent, but independent given C (Murphy 2012). No undirected graph can encode the collider’s pair of statements. Undirected independence is monotonic: once C separates A from B, adding more conditioning variables cannot reconnect them. In a DAG conditioning can create dependence, through “explaining away” (Murphy 2012).

The reverse also fails. A four-cycle A-B-C-D-A asserts that A and C are independent given B and D, and that B and D are independent given A and C. Every DAG you try gets at least one of these wrong (Murphy 2012). So neither language is more powerful: each perfectly represents some distributions the other cannot. Graphs that both can represent are called chordal (or decomposable). If you merge each maximal clique into one super-variable, the result is a tree (Murphy 2012).

The standard bridge is moralisation: “marry” the unmarried parents of every common child, then drop the arrows. It avoids false independences but loses some true ones, so to test a particular independence in a DAG Murphy first keeps only the variables involved and their ancestors, moralises that smaller graph, and then checks separation (Murphy 2012).

Writing down the joint: potentials and the partition function

A DAG factorises by the chain rule: one conditional probability per node. An undirected graph has no order, so it uses potential functions instead: one non-negative function \psi_c per clique (a set of nodes that are all joined to each other), multiplied together and divided by a normalising constant, p(y) = \frac{1}{Z}\prod_c \psi_c(y_c). The Hammersley–Clifford theorem says that any strictly positive distribution with the graph’s independences can be written this way, and vice versa (Murphy 2012). Murphy adds that the proof was never published. The constant Z, summed over every possible configuration, is the partition function. The letter comes from the German Zustandssumme, “sum over states”, a nod to the statistical physicists who got there first (Murphy 2012).

Writing \psi_c = \exp(-E_c) gives the physicists’ Gibbs distribution: each clique has an energy, low-energy configurations are the probable ones, and such models are called energy-based models (Murphy 2012). The most common simplification puts potentials on edges only, a pairwise MRF (Murphy 2012).

The key warning is that potentials are not probabilities. They measure the relative “compatibility” of local patterns (Murphy 2012). A small example with our own numbers shows why the difference matters. Give three yes/no variables the same edge potential: e^{1}\approx 2.72 when the two ends agree and e^{-1}\approx 0.37 when they disagree.

Graph Z P(A=B) P(A=+\mid B=+, C=+) P(A=+\mid B=+, C=-)
Chain A-B-C 19.05 0.881 0.881 0.881
Triangle A-B-C-A 42.38 0.965 0.982 0.500

In the chain, A’s probability given B does not move when C changes: B separates them. In the triangle the same local potential on the A–B edge yields a different marginal agreement (0.965 rather than 0.881), because the other edges push A and B together too. You cannot read a probability off one potential. You have to normalise over the whole graph, and that is the expensive part.

Potentials are usually written in log-linear form, \log\psi_c = \theta_c^\top\phi_c(y_c): a weight on each feature of the clique. This is also called a maximum-entropy model (Murphy 2012). The features need not be a full table. Murphy’s example is a model of English spelling: a full table over letter triples has 26^3 = 17{,}576 entries, almost all never seen, whereas a handful of indicator features (“ing”, “qu”) with weights tied across positions gives a probability to a word of any length (Murphy 2012).

A gallery of MRFs

The Ising model. Each node is a spin, y_s\in\{-1,+1\}, on a lattice, with a coupling w_{st} on each edge (Murphy 2012). Positive couplings make neighbours agree (a ferromagnet). If they are strong enough the distribution has two modes, all +1 and all -1, the ground states. Negative couplings make neighbours disagree (an anti-ferromagnet), which produces a frustrated system in which not every constraint can be satisfied at once (Murphy 2012). The Ising model looks like a Gaussian written in terms of its inverse covariance, but with one large difference. A Gaussian’s normalising constant is a determinant, computable in O(D^3) time. The Ising Z is a sum over all 2^D configurations, which is NP-hard in general (it is polynomial for purely attractive couplings) (Murphy 2012).

Hopfield networks and Boltzmann machines. A fully connected Ising model with learned weights can store patterns as an associative memory: show it part of a training image and it fills in the rest (Murphy 2012). Exact inference is intractable, so the standard method is iterated conditional modes: set each node to its most likely value given its neighbours, and repeat. Add hidden nodes and you have a Boltzmann machine, usually run with Gibbs sampling, the random version of the same update (Murphy 2012).

The Potts model. Replace the two spins with K labels and reward neighbours for sharing a label (Murphy 2012). Murphy shows samples from a 10-state Potts model: below a coupling of about 1.44 there are many small clusters, above it large ones, and near it a mix. This sudden change in behaviour as a parameter crosses a value is a phase transition (Murphy 2012). The Potts model is used as a prior for image segmentation. With a likelihood attached to each pixel it becomes a 2-D analogue of a hidden Markov model, but inference is provably much harder than on a chain and needs approximation (Murphy 2012). Murphy’s footnote is a warning about sampling: the influential paper that introduced the Gibbs sampler used exactly this prior, and its results were misleading because the sampler was not run long enough (Murphy 2012).

Gaussian MRFs. For continuous variables, a pairwise MRF with quadratic potentials is a multivariate normal written in terms of its precision matrix \Lambda=\Sigma^{-1}. Two variables are conditionally independent given the rest exactly when \Lambda_{st}=0; Murphy calls these zeros structural zeros, because each one is a missing edge (Murphy 2012). Learning the graph is therefore learning a sparse precision matrix, which is what the graphical lasso does (see structure learning). Jacobucci, Grimm and Zhang apply it to the 12 Grit items: items loading on the same factor end up strongly connected, and a node’s centrality correlates 0.82–0.91 with its factor-model R^2 (Jacobucci et al. 2023). Do not confuse this with a covariance graph, where a missing edge means a zero in \Sigma (marginal independence), not in \Lambda. Each edge of a covariance graph can be read as a hidden common cause, the bidirected edges of structural equation models (Murphy 2012).

Markov logic networks. Relational rules can define an MRF too. Murphy’s example is two rules: “smoking causes cancer” and “if two people are friends and one smokes, so does the other” (Murphy 2012). Hard logical rules are brittle, so each rule gets a weight, and for any set of people the rules are “grounded” into a network. With two people, Anna and Bob, that is eight binary nodes. The weight says how much more probable a world that satisfies the rule is than one that breaks it (Murphy 2012). The MRF says that friends’ smoking goes together. It does not tell you why: see the pitfalls below.

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.colors import ListedColormap

L, BURN, KEEP = 40, 600, 600
ii, jj = np.indices((L, L))
masks = [(ii + jj) % 2 == k for k in (0, 1)]       # checkerboard: neighbours never share a colour

def gibbs(J, seed=0):
    rng = np.random.default_rng(seed)
    s = rng.choice([-1, 1], size=(L, L))
    mags = []
    for sweep in range(BURN + KEEP):
        for mk in masks:
            nb = (np.roll(s, 1, 0) + np.roll(s, -1, 0) +
                  np.roll(s, 1, 1) + np.roll(s, -1, 1))
            p_up = 1 / (1 + np.exp(-2 * J * nb))    # full conditional p(s_i = +1 | neighbours)
            s = np.where(mk, np.where(rng.random((L, L)) < p_up, 1, -1), s)
        if sweep >= BURN:
            mags.append(abs(s.mean()))
    return np.mean(mags), s

def mean_field(J, n=4):
    m = 0.9
    for _ in range(5000):                          # iterate m = tanh(n J m) to its fixed point
        m = np.tanh(n * J * m)
    return abs(m)

Js = np.round(np.arange(0.10, 0.801, 0.025), 3)
sim = np.array([gibbs(J)[0] for J in Js])
mf = np.array([mean_field(J) for J in np.linspace(0.10, 0.80, 300)])

fig = plt.figure(figsize=(8.6, 6.4))
gs = fig.add_gridspec(2, 3, height_ratios=[1, 1.15])
spin_cmap = ListedColormap(["#161613", "#edece3"])
for k, J in enumerate([0.30, 0.44, 0.60]):
    ax = fig.add_subplot(gs[0, k])
    ax.imshow(gibbs(J)[1], cmap=spin_cmap, vmin=-1, vmax=1, interpolation="nearest")
    ax.set_title(f"J = {J:.2f}", fontsize=10)
    ax.set_xticks([]); ax.set_yticks([])
    ax.grid(False)

ax = fig.add_subplot(gs[1, :])
ax.plot(np.linspace(0.10, 0.80, 300), mf, color="#161613", lw=1.6, ls="--",
        label="mean field: m = tanh(4Jm)")
ax.plot(Js, sim, "o-", color="#e8531d", lw=1.8, ms=4,

ax.set_xlabel("coupling strength J")
ax.set_ylabel("average |magnetisation|")

The phase transition, and what the mean field misses

The figure samples an Ising model one spin at a time. Each spin’s update needs only its four neighbours (its Markov blanket), which is why Gibbs sampling suits MRFs: the hard global constant Z never appears. With weak coupling the spins are almost independent and the lattice looks like static. With strong coupling one sign takes over (which sign is chance: the two ordered states are mirror images). In between the change is not gradual: it happens over a narrow range of J.

Strogatz poses the same model as an exercise on bifurcations (Strogatz 2015). At high temperature the spins point at random and the average spin m is near zero; as temperature falls past a critical value the material magnetises spontaneously. Because up and down are symmetric, there are two ordered states, and an external field breaks the tie (Strogatz 2015). His equation for the equilibrium comes from the mean-field approximation, which replaces each spin’s neighbours by the average spin. Without a field it reduces to m=\tanh(nJm/T), with n neighbours per spin. Setting T=1 and n=4 to match the figure (our own step), a nonzero solution appears once J passes 1/4: the pitchfork bifurcation of the complexity track.

The simulated lattice needs a stronger coupling than that, around 0.4–0.5 in our run. Mean field counts each neighbour’s average as independent support, so it overstates how easily the lattice orders. That is the same overconfidence the variational-inference entry found in a two-spin example, and the same “zeroth-order first look” verdict Sayama gives the mean field on networks.

Fitting an MRF: why Z makes it hard

In log-linear form the log-likelihood is concave, so it has a single maximum (Murphy 2012). Its gradient has a clean reading: for each feature, the average in the data minus the average the model expects. The first term (“clamped”) fixes the variables at their observed values. The second (“unclamped”) lets them vary, and computing it needs inference in the model at every gradient step. That is why undirected models train much more slowly than directed ones (Murphy 2012). At the optimum the two averages are equal, which is called moment matching (Murphy 2012).

Several shortcuts avoid computing Z exactly (Murphy 2012):

  • Pseudo-likelihood (Besag 1975) maximises the product of each variable’s conditional distribution given its neighbours, and each of those needs only a sum over one variable’s values. For Gaussian MRFs it gives the same answer as maximum likelihood. In general it does not, but experiments suggest it works as well as exact ML for fully observed Ising models, and it is much faster (Murphy 2012). It has two weaknesses: it is hard to apply with hidden variables, and a node can learn to lean entirely on a neighbour that predicts it perfectly, ignoring its own evidence (Murphy 2012).
  • Stochastic maximum likelihood estimates the model average by MCMC. Instead of running a fresh chain to convergence at every step, it starts from where the last step’s chain stopped and runs only a few iterations, which is valid because the parameters barely moved (Younes 1989) (Murphy 2012).
  • Feature induction grows the feature set greedily. In the spelling model the first feature added is “this letter is lower case”, with weight 1.944: a lower-case letter in a position makes a word about e^{1.944}\approx 7 times more likely. With 1,000 features, samples start to look like English (“was”, “reaser”, “homes”, “thing”) (Murphy 2012).

Iterative proportional fitting, a.k.a. raking

For tables of counts, moment matching says the model’s fitted marginal tables must equal the observed ones. Iterative proportional fitting (IPF; Fienberg 1970) enforces this directly. It cycles through the cliques, rescaling each potential by (observed marginal) ÷ (model marginal), and it converges to the global optimum (Murphy 2012). Murphy’s example is handedness in a sample of 100 people:

Right-handed Left-handed Total
Male 43 9 52
Female 44 4 48
Total 87 13 100

Fit a model with no edge between sex and handedness. Moment matching says only the row and column totals must match, and the answer is 45.24, 6.76, 41.76 and 6.24 (Murphy 2012). The cells are the independence predictions, row total × column total ÷ 100. Because this graph is decomposable, IPF gets there in one cycle (we checked: further cycles change nothing), as Murphy notes for all decomposable graphs, where the maximum likelihood estimate has a closed form (Murphy 2012). This is the same algorithm the survey track calls raking: adjust weights until every known margin matches.

Conditional random fields

A conditional random field (CRF) is an MRF whose potentials depend on observed inputs x, so it models p(y\mid x) directly (Murphy 2012). Murphy describes it as a structured-output extension of logistic regression. Like any discriminative model it does not spend effort modelling the inputs, and it can let the potentials depend on features of the whole input, for example switching off smoothing between two pixels when the image shows an edge between them. The costs are that it needs labelled data and is slower to train (Murphy 2012).

The commonest kind is a chain, used for sequence labelling. An HMM is the generative alternative. Reversing its arrows gives a directed discriminative model, the maximum-entropy Markov model, which suffers from the label-bias problem: evidence later in a sequence cannot flow back to earlier labels (Murphy 2012). Murphy’s example is part-of-speech tagging. “Banks” alone could be a verb or a noun; a later “fishing” settles it as river banks, but in the directed model that evidence never reaches the earlier tag. The cause is local normalisation: each directed step must sum to one by itself. A CRF normalises globally, once, over whole label sequences, so the problem disappears. The price is that it has no valid distribution until it has seen the whole sequence, which rules it out for real-time use (Murphy 2012).

Murphy’s applications show the range (Murphy 2012): handwriting recognition, where context separates an “r” from a “c” in brace; noun-phrase chunking with Begin / Inside / Outside tags; named-entity recognition, where a “skip-chain” links repeated words so they get the same tag, which makes the graph depend on the input and inference harder; and stereo vision, where a truncated smoothness penalty lets depth jump at object boundaries instead of smearing across them. Training needs inference for every training case at every step, because Z now depends on the input: N times slower than an unconditional MRF (Murphy 2012). Chunking and entity tagging are ways of turning raw text into variables, the problem of text as data.

Common pitfalls

WarningWhere this goes wrong
  • Reading a potential as a probability. A potential is a relative compatibility score. The same edge potential implies different marginal probabilities in different graphs (0.881 in our chain, 0.965 in our triangle); only the normalised joint gives probabilities. (Murphy 2012)
  • Reading an edge as influence. An undirected edge is a symmetric conditional dependence. It cannot say who affects whom, and Murphy lists less interpretable parameters among MRFs’ main drawbacks. A network in which friends’ smoking goes together is not evidence of peer effects, which need a design. (Our gloss.) (Murphy 2012)
  • Converting a DAG by deleting arrowheads. A collider becomes a chain and asserts a false independence. Moralise instead, and test independences on the ancestral graph. (Murphy 2012)
  • Mixing up the two sparse graphs. A zero in the precision matrix means conditional independence (Gaussian MRF); a zero in the covariance matrix means marginal independence (covariance graph). (Murphy 2012)
  • Trusting a short Gibbs run near a phase transition. Large domains move slowly. The image-segmentation paper that introduced the Gibbs sampler drew misleading conclusions from a chain that was not run long enough. (Murphy 2012)
  • Using a mean-field threshold as the real one. Mean field ignores who is next to whom and overstates ordering (0.25 against roughly 0.4–0.5 in the figure). (Strogatz 2015)
  • Pseudo-likelihood with a perfect-predictor neighbour. A node can learn to rely only on that neighbour and ignore its own evidence. (Murphy 2012)

Appendix · the mathematics

Markov properties. For a graph G on nodes V: global, x_A\perp x_B\mid x_C whenever C separates A from B; local, t\perp V\setminus \mathrm{cl}(t)\mid \mathrm{mb}(t) with \mathrm{mb}(t) the neighbours and \mathrm{cl}(t)=\mathrm{mb}(t)\cup\{t\}; pairwise, s\perp t\mid V\setminus\{s,t\}\iff G_{st}=0. Global ⇒ local ⇒ pairwise always; pairwise ⇒ global when p(x)>0 for all x.

Hammersley–Clifford and the Gibbs form. A positive p satisfies the independences of G iff p(y\mid\theta)=\frac{1}{Z(\theta)}\prod_{c\in\mathcal C}\psi_c(y_c\mid\theta_c),\qquad Z(\theta)=\sum_{y}\prod_{c}\psi_c(y_c\mid\theta_c), over the maximal cliques \mathcal C. With \psi_c=\exp(-E_c) this is p\propto\exp(-\sum_c E_c).

The worked table. With edge potential e^{y_sy_t}: the chain has Z = 2e^2+4+2e^{-2}=19.05 and, because B separates A from C, P(A=B)=e/(e+e^{-1})=0.881 whatever C is. The triangle has Z=2e^3+6e^{-1}=42.38 (two all-agree states, six with one odd spin out), and P(A=B)=(2e^3+2e^{-1})/Z=0.965.

Ising full conditional. With \log\tilde p(y)=\sum_{s\sim t}w_{st}y_sy_t+\sum_s b_sy_s and y_s\in\{\pm1\}, only terms touching s survive the ratio, so p(y_s=+1\mid y_{-s})=\frac{1}{1+\exp\!\big(-2(\sum_{t}w_{st}y_t+b_s)\big)}, the update in the figure’s code (w_{st}=J, b_s=0, four neighbours).

Mean field and the critical coupling. Strogatz’s equation is h=T\tanh^{-1}m-Jnm. With h=0, m=\tanh(Jnm/T). The line m\mapsto \tanh(am) has slope a at 0, so a nonzero root exists iff a=Jn/T>1, giving T_c=Jn; in the figure’s units (T=1, n=4) the threshold is J=1/4. Near it, m^2\approx 3(a-1)/a^3: a pitchfork.

Gaussian MRF. p(y)\propto\exp(\eta^\top y-\tfrac12 y^\top\Lambda y) with \Lambda=\Sigma^{-1}, \eta=\Lambda\mu, and y_s\perp y_t\mid y_{-st}\iff\Lambda_{st}=0.

Learning by moment matching. For p(y\mid\theta)=Z(\theta)^{-1}\exp(\sum_c\theta_c^\top\phi_c(y)), \partial\log Z/\partial\theta_c=E_\theta[\phi_c(y)], so \frac{\partial\ell}{\partial\theta_c}=\frac1N\sum_i\phi_c(y_i)-E_\theta[\phi_c(y)] =E_{p_{\text{emp}}}[\phi_c]-E_{p(\cdot\mid\theta)}[\phi_c], zero at the optimum. The log-likelihood is concave (exponential family), so the optimum is unique.

Pseudo-likelihood. \ell_{PL}(\theta)=\frac1N\sum_{i}\sum_{d}\log p(y_{id}\mid y_{i,-d},\theta); each term normalises over one variable only.

IPF. Repeat over cliques: \psi_c\leftarrow\psi_c\cdot p_{\text{emp}}(y_c)/p(y_c\mid\psi). For the handedness table with no edge, the fixed point is \hat m_{jk}=n_{j\cdot}\,n_{\cdot k}/n: 52\times87/100=45.24, and so on.

CRF. p(y\mid x,w)=Z(x,w)^{-1}\prod_c\exp(w_c^\top\phi(x,y_c)), with gradient \frac1N\sum_i[\phi_c(y_i,x_i)-E\,\phi_c(y,x_i)], one inference per training case per step.

::: {.lead-kernel}
A **Markov random field (MRF)**, or **undirected graphical model**, describes variables that depend on their
neighbours without saying which one comes first. Two variables with no edge between them are independent
given everything else, and a variable's neighbours are all you need to know to predict it. The joint
distribution is a product of local **compatibility scores** divided by a **partition function** $Z$. That one
constant makes MRFs natural to write down and expensive to fit. The **Ising model**, Gaussian graphical
models and **conditional random fields** are all MRFs.
:::

## Why it matters

A [DAG](../05-causal-inference/directed-acyclic-graphs.qmd) asks you to point every arrow. For causal
questions that is the point. For some data it is awkward. Murphy's example is an image: neighbouring pixels
have similar intensities, but no pixel causes its neighbour [@murphy_ml]. You *can* force a 2-D grid into a
DAG (a "Markov mesh"), but the conditional independences come out unnatural. In Murphy's 20-node lattice the
set of nodes that shields the middle node $X_8$ from everything else is six nodes, its parents, children and
co-parents (3, 4, 7, 9, 12, 13), not the four nearest neighbours you would expect [@murphy_ml]. Drop the
arrows and that set becomes the four neighbours.

Murphy lists the trade-off plainly. Undirected models are **symmetric**, which suits spatial and relational
data, and their conditional versions (**CRFs**) make better discriminative sequence models than directed
ones. Against that, their parameters are **less interpretable and less modular**, and fitting them is **more
expensive** [@murphy_ml]. You have met MRFs already in this encyclopedia, under other names: the
[psychometric networks](../04-predictive/measurement-and-ml.qmd) of the measurement entry are Gaussian MRFs,
the image-denoising showcase in [variational inference](variational-inference.qmd) is an Ising model, and the
raking used to [calibrate survey weights](../02-inference/complex-survey-estimation.qmd) is the classic
algorithm for fitting a tabular MRF. This entry is the common machinery behind all three.

## Separation means independence

Conditional independence is simpler to read off an undirected graph than off a DAG. Take three sets of
nodes $A$, $B$ and $C$. If deleting $C$ leaves no path from $A$ to $B$, then $A$ is independent of $B$ given
$C$. Murphy calls this the **global Markov property** [@murphy_ml]. Two weaker readings follow from it:

- **Local:** a node's **Markov blanket**, the set that makes it independent of everything else, is just its
  **immediate neighbours** [@murphy_ml].
- **Pairwise:** two nodes with **no edge** between them are independent given all the rest [@murphy_ml].

Global implies local implies pairwise. The surprising part is that, as long as every configuration has
positive probability, pairwise also implies global, so the three readings coincide [@murphy_ml]. That
matters in practice. Pairwise statements are the easiest to check in data, and they are enough to build a
graph from which every other independence can be read [@murphy_ml]. This is how a psychometric network is
built: estimate which pairs of items are independent given all the others, and leave those edges out.

## Undirected and directed graphs say different things

You cannot turn a DAG into an undirected graph by deleting the arrowheads. A collider $A\to C\leftarrow B$
says $A$ and $B$ are independent but become dependent once you condition on $C$ (the
[collider bias](../05-causal-inference/directed-acyclic-graphs.qmd) of the causal track). The chain
$A - C - B$ says the opposite: dependent, but independent given $C$ [@murphy_ml]. **No undirected graph** can
encode the collider's pair of statements. Undirected independence is **monotonic**: once $C$ separates $A$
from $B$, adding more conditioning variables cannot reconnect them. In a DAG conditioning can create
dependence, through "explaining away" [@murphy_ml].

The reverse also fails. A four-cycle $A-B-C-D-A$ asserts that $A$ and $C$ are independent given $B$ and $D$,
and that $B$ and $D$ are independent given $A$ and $C$. Every DAG you try gets at least one of these wrong
[@murphy_ml]. So neither language is more powerful: each perfectly represents some distributions the other
cannot. Graphs that both can represent are called **chordal** (or decomposable). If you merge each maximal
clique into one super-variable, the result is a tree [@murphy_ml].

The standard bridge is **moralisation**: "marry" the unmarried parents of every common child, then drop the
arrows. It avoids false independences but loses some true ones, so to test a particular independence in a
DAG Murphy first keeps only the variables involved and their ancestors, moralises that smaller graph, and
then checks separation [@murphy_ml].

## Writing down the joint: potentials and the partition function

A DAG factorises by the chain rule: one conditional probability per node. An undirected graph has no order,
so it uses **potential functions** instead: one non-negative function $\psi_c$ per clique (a set of nodes
that are all joined to each other), multiplied together and divided by a normalising constant,
$$
p(y) = \frac{1}{Z}\prod_c \psi_c(y_c).
$$
The **Hammersley–Clifford theorem** says that any strictly positive distribution with the graph's
independences can be written this way, and vice versa [@murphy_ml]. Murphy adds that the proof was never
published. The constant $Z$, summed over every possible configuration, is the **partition function**. The
letter comes from the German *Zustandssumme*, "sum over states", a nod to the statistical physicists who got
there first [@murphy_ml].

Writing $\psi_c = \exp(-E_c)$ gives the physicists' **Gibbs distribution**: each clique has an **energy**,
low-energy configurations are the probable ones, and such models are called **energy-based models**
[@murphy_ml]. The most common simplification puts potentials on edges only, a **pairwise MRF**
[@murphy_ml].

The key warning is that **potentials are not probabilities**. They measure the relative "compatibility" of
local patterns [@murphy_ml]. A small example with our own numbers shows why the difference matters. Give
three yes/no variables the same edge potential: $e^{1}\approx 2.72$ when the two ends agree and
$e^{-1}\approx 0.37$ when they disagree.

| Graph | $Z$ | $P(A=B)$ | $P(A=+\mid B=+, C=+)$ | $P(A=+\mid B=+, C=-)$ |
|---|---|---|---|---|
| Chain $A-B-C$ | 19.05 | 0.881 | 0.881 | 0.881 |
| Triangle $A-B-C-A$ | 42.38 | **0.965** | 0.982 | 0.500 |

In the chain, $A$'s probability given $B$ does not move when $C$ changes: $B$ separates them. In the
triangle the same local potential on the $A$–$B$ edge yields a different marginal agreement (0.965 rather
than 0.881), because the other edges push $A$ and $B$ together too. You cannot read a probability off one
potential. You have to normalise over the whole graph, and that is the expensive part.

Potentials are usually written in **log-linear** form, $\log\psi_c = \theta_c^\top\phi_c(y_c)$: a weight on
each feature of the clique. This is also called a **maximum-entropy model** [@murphy_ml]. The features need
not be a full table. Murphy's example is a model of English spelling: a full table over letter triples has
$26^3 = 17{,}576$ entries, almost all never seen, whereas a handful of indicator features ("ing", "qu") with
weights tied across positions gives a probability to a word of any length [@murphy_ml].

## A gallery of MRFs

**The Ising model.** Each node is a spin, $y_s\in\{-1,+1\}$, on a lattice, with a coupling $w_{st}$ on each
edge [@murphy_ml]. Positive couplings make neighbours agree (a ferromagnet). If they are strong enough the
distribution has two modes, all $+1$ and all $-1$, the **ground states**. Negative couplings make neighbours
disagree (an anti-ferromagnet), which produces a **frustrated** system in which not every constraint can be
satisfied at once [@murphy_ml]. The Ising model looks like a Gaussian written in terms of its inverse
covariance, but with one large difference. A Gaussian's normalising constant is a determinant, computable in
$O(D^3)$ time. The Ising $Z$ is a sum over all $2^D$ configurations, which is NP-hard in general (it is
polynomial for purely attractive couplings) [@murphy_ml].

**Hopfield networks and Boltzmann machines.** A fully connected Ising model with learned weights can store
patterns as an **associative memory**: show it part of a training image and it fills in the rest
[@murphy_ml]. Exact inference is intractable, so the standard method is **iterated conditional modes**: set
each node to its most likely value given its neighbours, and repeat. Add hidden nodes and you have a
**Boltzmann machine**, usually run with [Gibbs sampling](../02-inference/mcmc-in-depth.qmd), the random
version of the same update [@murphy_ml].

**The Potts model.** Replace the two spins with $K$ labels and reward neighbours for sharing a label
[@murphy_ml]. Murphy shows samples from a 10-state Potts model: below a coupling of about 1.44 there are many
small clusters, above it large ones, and near it a mix. This sudden change in behaviour as a parameter
crosses a value is a **phase transition** [@murphy_ml]. The Potts model is used as a prior for image
segmentation. With a likelihood attached to each pixel it becomes a 2-D analogue of a
[hidden Markov model](hidden-markov-models.qmd), but inference is provably much harder than on a chain and
needs approximation [@murphy_ml]. Murphy's footnote is a warning about sampling: the influential paper that
introduced the Gibbs sampler used exactly this prior, and its results were misleading because the sampler was
not run long enough [@murphy_ml].

**Gaussian MRFs.** For continuous variables, a pairwise MRF with quadratic potentials is a multivariate
normal written in terms of its **precision matrix** $\Lambda=\Sigma^{-1}$. Two variables are conditionally
independent given the rest exactly when $\Lambda_{st}=0$; Murphy calls these zeros **structural zeros**,
because each one is a missing edge [@murphy_ml]. Learning the graph is therefore learning a **sparse precision
matrix**, which is what the **graphical lasso** does (see [structure learning](structure-learning.qmd)). Jacobucci, Grimm and Zhang apply it to the 12 Grit
items: items loading on the same factor end up strongly connected, and a node's centrality correlates
0.82–0.91 with its factor-model $R^2$ [@jacobucci_ml]. Do not confuse this with a **covariance graph**, where
a missing edge means a zero in $\Sigma$ (marginal independence), not in $\Lambda$. Each edge of a covariance
graph can be read as a hidden common cause, the bidirected edges of
[structural equation models](../03-regression/structural-equation-models.qmd) [@murphy_ml].

**Markov logic networks.** Relational rules can define an MRF too. Murphy's example is two rules: "smoking
causes cancer" and "if two people are friends and one smokes, so does the other" [@murphy_ml]. Hard logical
rules are brittle, so each rule gets a weight, and for any set of people the rules are "grounded" into a
network. With two people, Anna and Bob, that is eight binary nodes. The weight says how much more probable a
world that satisfies the rule is than one that breaks it [@murphy_ml]. The MRF says that friends' smoking
goes together. It does not tell you why: see the pitfalls below.

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.colors import ListedColormap

L, BURN, KEEP = 40, 600, 600
ii, jj = np.indices((L, L))
masks = [(ii + jj) % 2 == k for k in (0, 1)]       # checkerboard: neighbours never share a colour

def gibbs(J, seed=0):
    rng = np.random.default_rng(seed)
    s = rng.choice([-1, 1], size=(L, L))
    mags = []
    for sweep in range(BURN + KEEP):
        for mk in masks:
            nb = (np.roll(s, 1, 0) + np.roll(s, -1, 0) +
                  np.roll(s, 1, 1) + np.roll(s, -1, 1))
            p_up = 1 / (1 + np.exp(-2 * J * nb))    # full conditional p(s_i = +1 | neighbours)
            s = np.where(mk, np.where(rng.random((L, L)) < p_up, 1, -1), s)
        if sweep >= BURN:
            mags.append(abs(s.mean()))
    return np.mean(mags), s

def mean_field(J, n=4):
    m = 0.9
    for _ in range(5000):                          # iterate m = tanh(n J m) to its fixed point
        m = np.tanh(n * J * m)
    return abs(m)

Js = np.round(np.arange(0.10, 0.801, 0.025), 3)
sim = np.array([gibbs(J)[0] for J in Js])
mf = np.array([mean_field(J) for J in np.linspace(0.10, 0.80, 300)])

## The phase transition, and what the mean field misses

The figure samples an Ising model one spin at a time. Each spin's update needs only its four neighbours (its
Markov blanket), which is why Gibbs sampling suits MRFs: the hard global constant $Z$ never appears. With weak
coupling the spins are almost independent and the lattice looks like static. With strong coupling one sign
takes over (which sign is chance: the two ordered states are mirror images). In between the change is not gradual: it happens over a narrow range of $J$.

Strogatz poses the same model as an exercise on bifurcations [@strogatz_nonlinear]. At high temperature the
spins point at random and the average spin $m$ is near zero; as temperature falls past a critical value the
material magnetises spontaneously. Because up and down are symmetric, there are **two** ordered states, and an
external field breaks the tie [@strogatz_nonlinear]. His equation for the equilibrium comes from the
**mean-field approximation**, which replaces each spin's neighbours by the average spin. Without a field it
reduces to $m=\tanh(nJm/T)$, with $n$ neighbours per spin. Setting $T=1$ and $n=4$ to match the figure (our
own step), a nonzero solution appears once $J$ passes $1/4$: the
[pitchfork bifurcation](../complexity/bifurcations-and-tipping-points.qmd) of the complexity track.

The simulated lattice needs a stronger coupling than that, around 0.4–0.5 in our run. Mean field counts each
neighbour's average as independent support, so it overstates how easily the lattice orders. That is the same
overconfidence the [variational-inference entry](variational-inference.qmd) found in a two-spin example, and
the same "zeroth-order first look" verdict Sayama gives the
[mean field on networks](../complexity/spreading-on-networks.qmd#sec-mean-field).

## Fitting an MRF: why $Z$ makes it hard

In log-linear form the log-likelihood is concave, so it has a single maximum [@murphy_ml]. Its gradient has
a clean reading: for each feature, the **average in the data** minus the **average the model expects**. The
first term ("clamped") fixes the variables at their observed values. The second ("unclamped") lets them vary,
and computing it needs inference in the model at every gradient step. That is why undirected models train
much more slowly than directed ones [@murphy_ml]. At the optimum the two averages are equal, which is called
**moment matching** [@murphy_ml].

Several shortcuts avoid computing $Z$ exactly [@murphy_ml]:

- **Pseudo-likelihood** (Besag 1975) maximises the product of each variable's conditional distribution given
  its neighbours, and each of those needs only a sum over one variable's values. For Gaussian MRFs it gives the
  same answer as maximum likelihood. In general it does not, but experiments suggest it works as well as exact
  ML for fully observed Ising models, and it is much faster [@murphy_ml]. It has two weaknesses: it is hard to
  apply with hidden variables, and a node can learn to lean entirely on a neighbour that predicts it
  perfectly, ignoring its own evidence [@murphy_ml].
- **Stochastic maximum likelihood** estimates the model average by MCMC. Instead of running a fresh chain to
  convergence at every step, it starts from where the last step's chain stopped and runs only a few
  iterations, which is valid because the parameters barely moved (Younes 1989) [@murphy_ml].
- **Feature induction** grows the feature set greedily. In the spelling model the first feature added is
  "this letter is lower case", with weight 1.944: a lower-case letter in a position makes a word about
  $e^{1.944}\approx 7$ times more likely. With 1,000 features, samples start to look like English ("was",
  "reaser", "homes", "thing") [@murphy_ml].

### Iterative proportional fitting, a.k.a. raking

For tables of counts, moment matching says the model's fitted marginal tables must equal the observed ones.
**Iterative proportional fitting** (IPF; Fienberg 1970) enforces this directly. It cycles through the
cliques, rescaling each potential by (observed marginal) ÷ (model marginal), and it converges to the global
optimum [@murphy_ml]. Murphy's example is handedness in a sample of 100 people:

| | Right-handed | Left-handed | Total |
|---|---|---|---|
| Male | 43 | 9 | 52 |
| Female | 44 | 4 | 48 |
| Total | 87 | 13 | 100 |

Fit a model with **no edge** between sex and handedness. Moment matching says only the row and column totals
must match, and the answer is 45.24, 6.76, 41.76 and 6.24 [@murphy_ml]. The cells are the independence
predictions, row total × column total ÷ 100. Because this graph is decomposable, IPF gets there in one cycle
(we checked: further cycles change nothing), as Murphy notes for all decomposable graphs, where the maximum
likelihood estimate has a closed form [@murphy_ml]. This is the same algorithm the survey track calls
[raking](../02-inference/complex-survey-estimation.qmd): adjust weights until every known margin matches.

## Conditional random fields

A **conditional random field** (CRF) is an MRF whose potentials depend on observed inputs $x$, so it models
$p(y\mid x)$ directly [@murphy_ml]. Murphy describes it as a **structured-output extension of logistic
regression**. Like any discriminative model it does not spend effort modelling the inputs, and it can let the
potentials depend on features of the whole input, for example switching off smoothing between two pixels when
the image shows an edge between them. The costs are that it needs labelled data and is slower to train
[@murphy_ml].

The commonest kind is a chain, used for **sequence labelling**. An [HMM](hidden-markov-models.qmd) is the
generative alternative. Reversing its arrows gives a directed discriminative model, the
maximum-entropy Markov model, which suffers from the **label-bias problem**: evidence later in a sequence
cannot flow back to earlier labels [@murphy_ml]. Murphy's example is part-of-speech tagging. "Banks" alone
could be a verb or a noun; a later "fishing" settles it as river banks, but in the directed model that
evidence never reaches the earlier tag. The cause is **local normalisation**: each directed step must sum to
one by itself. A CRF normalises **globally**, once, over whole label sequences, so the problem disappears. The
price is that it has no valid distribution until it has seen the whole sequence, which rules it out for
real-time use [@murphy_ml].

Murphy's applications show the range [@murphy_ml]: handwriting recognition, where context separates an "r"
from a "c" in *brace*; **noun-phrase chunking** with Begin / Inside / Outside tags; **named-entity
recognition**, where a "skip-chain" links repeated words so they get the same tag, which makes the graph
depend on the input and inference harder; and stereo vision, where a **truncated** smoothness penalty lets
depth jump at object boundaries instead of smearing across them. Training needs inference for every training
case at every step, because $Z$ now depends on the input: $N$ times slower than an unconditional MRF
[@murphy_ml]. Chunking and entity tagging are ways of turning raw text into variables, the
problem of [text as data](../04-predictive/text-as-data.qmd).

## Common pitfalls

::: {.callout-warning title="Where this goes wrong"}
- **Reading a potential as a probability.** A potential is a relative compatibility score. The same edge
  potential implies different marginal probabilities in different graphs (0.881 in our chain, 0.965 in our
  triangle); only the normalised joint gives probabilities. [@murphy_ml]
- **Reading an edge as influence.** An undirected edge is a symmetric conditional dependence. It cannot say
  who affects whom, and Murphy lists less interpretable parameters among MRFs' main drawbacks. A network in
  which friends' smoking goes together is not evidence of
  [peer effects](../05-causal-inference/peer-effects-and-spillovers.qmd), which need a design. *(Our gloss.)*
  [@murphy_ml]
- **Converting a DAG by deleting arrowheads.** A collider becomes a chain and asserts a false independence.
  Moralise instead, and test independences on the ancestral graph. [@murphy_ml]
- **Mixing up the two sparse graphs.** A zero in the precision matrix means conditional independence (Gaussian
  MRF); a zero in the covariance matrix means marginal independence (covariance graph). [@murphy_ml]
- **Trusting a short Gibbs run near a phase transition.** Large domains move slowly. The image-segmentation
  paper that introduced the Gibbs sampler drew misleading conclusions from a chain that was not run long
  enough. [@murphy_ml]
- **Using a mean-field threshold as the real one.** Mean field ignores who is next to whom and overstates
  ordering (0.25 against roughly 0.4–0.5 in the figure). [@strogatz_nonlinear]
- **Pseudo-likelihood with a perfect-predictor neighbour.** A node can learn to rely only on that neighbour
  and ignore its own evidence. [@murphy_ml]
:::

## Appendix · the mathematics {#sec-mrf-math .unnumbered}

::: {.math-appendix}

**Markov properties.** For a graph $G$ on nodes $V$: global, $x_A\perp x_B\mid x_C$ whenever $C$ separates $A$
from $B$; local, $t\perp V\setminus \mathrm{cl}(t)\mid \mathrm{mb}(t)$ with $\mathrm{mb}(t)$ the neighbours
and $\mathrm{cl}(t)=\mathrm{mb}(t)\cup\{t\}$; pairwise, $s\perp t\mid V\setminus\{s,t\}\iff G_{st}=0$.
Global ⇒ local ⇒ pairwise always; pairwise ⇒ global when $p(x)>0$ for all $x$.

**Hammersley–Clifford and the Gibbs form.** A positive $p$ satisfies the independences of $G$ iff
$$
p(y\mid\theta)=\frac{1}{Z(\theta)}\prod_{c\in\mathcal C}\psi_c(y_c\mid\theta_c),\qquad
Z(\theta)=\sum_{y}\prod_{c}\psi_c(y_c\mid\theta_c),
$$
over the maximal cliques $\mathcal C$. With $\psi_c=\exp(-E_c)$ this is $p\propto\exp(-\sum_c E_c)$.

**The worked table.** With edge potential $e^{y_sy_t}$: the chain has $Z = 2e^2+4+2e^{-2}=19.05$ and, because
$B$ separates $A$ from $C$, $P(A=B)=e/(e+e^{-1})=0.881$ whatever $C$ is. The triangle has $Z=2e^3+6e^{-1}=42.38$
(two all-agree states, six with one odd spin out), and $P(A=B)=(2e^3+2e^{-1})/Z=0.965$.

**Ising full conditional.** With $\log\tilde p(y)=\sum_{s\sim t}w_{st}y_sy_t+\sum_s b_sy_s$ and $y_s\in\{\pm1\}$,
only terms touching $s$ survive the ratio, so
$$
p(y_s=+1\mid y_{-s})=\frac{1}{1+\exp\!\big(-2(\sum_{t}w_{st}y_t+b_s)\big)},
$$
the update in the figure's code ($w_{st}=J$, $b_s=0$, four neighbours).

**Mean field and the critical coupling.** Strogatz's equation is $h=T\tanh^{-1}m-Jnm$. With $h=0$,
$m=\tanh(Jnm/T)$. The line $m\mapsto \tanh(am)$ has slope $a$ at 0, so a nonzero root exists iff $a=Jn/T>1$,
giving $T_c=Jn$; in the figure's units ($T=1$, $n=4$) the threshold is $J=1/4$. Near it, $m^2\approx 3(a-1)/a^3$:
a pitchfork.

**Gaussian MRF.** $p(y)\propto\exp(\eta^\top y-\tfrac12 y^\top\Lambda y)$ with $\Lambda=\Sigma^{-1}$, $\eta=\Lambda\mu$,
and $y_s\perp y_t\mid y_{-st}\iff\Lambda_{st}=0$.

**Learning by moment matching.** For $p(y\mid\theta)=Z(\theta)^{-1}\exp(\sum_c\theta_c^\top\phi_c(y))$,
$\partial\log Z/\partial\theta_c=E_\theta[\phi_c(y)]$, so
$$
\frac{\partial\ell}{\partial\theta_c}=\frac1N\sum_i\phi_c(y_i)-E_\theta[\phi_c(y)]
=E_{p_{\text{emp}}}[\phi_c]-E_{p(\cdot\mid\theta)}[\phi_c],
$$
zero at the optimum. The log-likelihood is concave (exponential family), so the optimum is unique.

**Pseudo-likelihood.** $\ell_{PL}(\theta)=\frac1N\sum_{i}\sum_{d}\log p(y_{id}\mid y_{i,-d},\theta)$; each term
normalises over one variable only.

**IPF.** Repeat over cliques: $\psi_c\leftarrow\psi_c\cdot p_{\text{emp}}(y_c)/p(y_c\mid\psi)$. For the
handedness table with no edge, the fixed point is $\hat m_{jk}=n_{j\cdot}\,n_{\cdot k}/n$:
$52\times87/100=45.24$, and so on.

**CRF.** $p(y\mid x,w)=Z(x,w)^{-1}\prod_c\exp(w_c^\top\phi(x,y_c))$, with gradient
$\frac1N\sum_i[\phi_c(y_i,x_i)-E\,\phi_c(y,x_i)]$, one inference per training case per step.

:::
