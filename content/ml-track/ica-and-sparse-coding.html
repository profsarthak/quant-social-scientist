Beyond PCA: ICA, Sparse Coding & NMF

  • Show All Code
  • Hide All Code
  • View Source

PCA finds the plane the data live in but not the directions that matter inside it. Change one assumption, that the hidden sources are bell-shaped, and the directions become recoverable.

PCA can tell you which few directions hold most of the variation, but if the data are mixtures of hidden sources it cannot pull the sources apart: any rotation of its answer fits the data equally well. Independent component analysis breaks the tie by assuming the sources are not Gaussian. Sparse coding goes further and assumes each observation is built from only a few of many possible parts. Non-negative matrix factorisation insists the parts can only be added, never subtracted. Each is the same latent-factor model with a different belief about the hidden pieces.

Why it matters

PCA and factor analysis model each observation as a weighted sum of a few hidden factors. Both assume the factors are Gaussian, and that assumption has a cost which applied researchers meet as the rotation problem: the model identifies the space the factors span, but not a unique set of axes inside it. Factor analysts handle this by picking a rotation (varimax and its relatives) that is easy to interpret. Murphy’s point is that ICA is the same move made principled: once the factors are non-Gaussian, the data themselves say which rotation is right. (Murphy 2012)

The family matters for three reasons. First, it shows exactly which assumption makes latent factors identifiable. That question comes back in factor analysis, structural equation models and matrix factorisation. Second, it carries the lasso’s sparsity idea from supervised to unsupervised learning: instead of a few non-zero coefficients, a few active factors per observation. Third, it has some of machine learning’s best-known results: a model of how the visual cortex might encode images, and compressed sensing, which reconstructs an MRI scan from fewer measurements than pixels. (Murphy 2012)

One model, many priors

Every method here starts from the same equation. An observed vector x (the readings at D sensors, or D variables for one respondent) is a weighted sum of L hidden factors z, plus noise: x = Wz + \epsilon. The columns of W are the loadings (or, below, the atoms of a dictionary). The methods differ only in what they assume about z, about W, and about whether W’s columns must be orthogonal. Murphy collects them in one table: (Murphy 2012)

Method Prior on the factors z Prior on the loadings W W orthogonal?
PCA Gaussian none (estimated) yes
Factor analysis Gaussian none no
ICA non-Gaussian none yes
Sparse coding Laplace (sparse) none no
Sparse PCA Gaussian Laplace (sparse) maybe
Sparse matrix factorisation Laplace Laplace no

Read the table by its rows. ICA changes one cell of PCA’s row. Sparse coding takes ICA’s non-Gaussian factor prior, picks one that favours zeros, and drops the orthogonality. Sparse PCA puts the sparsity in a different place: on the loadings rather than the factors. Murphy warns against confusing the two. (Murphy 2012) NMF, below, replaces priors with a sign constraint.

The cocktail party: ICA

Murphy opens with the cocktail party problem. Several people talk at once in a crowded room. Your two ears are two microphones, and each picks up a different linear mixture of the voices. The task is to recover the separate voices from the mixtures. This is blind source separation: “blind” because you know nothing about the sources except that they were mixed. It arises in audio, in EEG and MEG brain recordings, in financial data, and in any dataset where hidden sources are mixed together linearly. (Murphy 2012) The model is x_t = Wz_t, where W is now called the mixing matrix and each z_t holds the sources at time t. Each time point is treated as an independent draw; ICA ignores the order. (Murphy 2012)

Why PCA cannot do it

PCA assumes each source is an independent standard Gaussian. A cloud of independent standard Gaussians is perfectly round, and a round cloud looks the same after any rotation. So if (W, z) explains the data, so does (WR^\top, Rz) for any rotation R, and the likelihood cannot tell them apart. PCA finds the best linear subspace, but it “cannot uniquely recover the signals themselves”. (Murphy 2012)

Murphy’s two-dimensional demonstration makes this visible. Take two independent sources, each uniform (so their joint distribution is a square), and mix them with W = \left(\begin{smallmatrix}2 & 3\\ 2 & 1\end{smallmatrix}\right). The square becomes a slanted parallelogram. PCA followed by rescaling, a step called whitening, turns the parallelogram back into a square of the right size, but tilted at an arbitrary angle. A Gaussian contains no information about which angle to rotate back by. In Murphy’s phrase, PCA solves “half” of the problem: it finds the subspace, and ICA’s only remaining job is to find the rotation. (Murphy 2012) Figure 1 rebuilds the demonstration.

What ICA assumes instead

ICA keeps the independence of the sources and drops the bell shape: each source may have any non-Gaussian distribution, with variance fixed at 1 so that scale lives in W. (Murphy 2012) Murphy names three ways to be non-Gaussian, measured by kurtosis (how peaked and heavy-tailed a distribution is, relative to a Gaussian) and skewness (how lopsided it is): (Murphy 2012)

  • Super-Gaussian (positive excess kurtosis): a sharp spike at the mean and heavy tails. The Laplace distribution is the classic case. Natural signals such as images and speech, passed through certain linear filters, look like this.
  • Sub-Gaussian (negative excess kurtosis): flatter than a Gaussian. The uniform distribution is the classic case.
  • Skewed: asymmetric, like the gamma distribution.

In practice the exact source shape matters less than you might fear. When ICA is fitted by maximum likelihood, it is “not critical” to know the exact source distribution, but it is important to know whether it is sub- or super-Gaussian; a smooth stand-in such as \log\cosh is commonly used. (Murphy 2012)

What ICA gives back is the sources up to permutation and sign: it cannot know which voice you called “first”, nor whether a source was recorded upside down. (Murphy 2012) It also needs as many sensors as sources (W square). With more sources than sensors, the sources cannot be recovered uniquely; the best you can do is a posterior over them. (Murphy 2012)

How it is fitted

The standard route is to centre and whiten the data first. After whitening, the remaining unmixing matrix must be orthogonal: a pure rotation. In D dimensions this cuts the unknowns from D^2 to D(D-1)/2. In two dimensions that leaves a single angle. (Murphy 2012) Then:

  • FastICA (Hyvärinen & Oja) is an approximate Newton method. Each update is cheap, the directions are renormalised after every step, and convergence is checked on the direction rather than the sign. The objective is not convex, so there are several local optima. FastICA uses them: it finds several components at once and keeps them orthogonal. Unlike PCA, the components have no natural order; the first is not “more important” than the second. (Murphy 2012)
  • EM with flexible sources. Instead of fixing a source shape, model each source as a mixture of Gaussians and alternate between estimating the source densities and the mixing matrix. Murphy cites Moulines et al. (1997) and Attias (1999) for this independent factor analysis model. (Murphy 2012)

Murphy then shows that three other ways of motivating ICA all lead back to maximum likelihood once the data are whitened and the unmixing is orthogonal: making the components as non-Gaussian as possible (through negentropy, a cousin of projection pursuit), making them as independent as possible (minimising mutual information), and maximising the information flow through a simple neural network (infomax, Bell & Sejnowski 1995). (Murphy 2012) The appendix gives the short argument.

See it

The figure is our own simulation in the spirit of Murphy’s Figure 12.21: 500 draws of two independent uniform sources, mixed by his matrix W. The top row follows the data through PCA and ICA. The bottom panel shows why ICA can find the right angle: it measures the kurtosis of the whitened data projected on every direction.

Show the figure code (whitening and FastICA by hand) 
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(7)
N = 500
S = rng.uniform(-np.sqrt(3), np.sqrt(3), size=(2, N))   # unit-variance uniform sources
W = np.array([[2.0, 3.0], [2.0, 1.0]])                   # Murphy's mixing matrix (eq 12.98)
X = W @ S

# --- PCA + whitening: rotate to the eigenvectors, rescale each axis to unit variance ---
Xc = X - X.mean(1, keepdims=True)
vals, vecs = np.linalg.eigh(np.cov(Xc))
Z = np.diag(vals ** -0.5) @ vecs.T @ Xc

# --- symmetric FastICA with G(u) = log cosh u, so g = tanh and g' = 1 - tanh^2 ---
V = np.linalg.qr(rng.normal(size=(2, 2)))[0]
for _ in range(200):
    Y = V @ Z
    g = np.tanh(Y)
    Vn = (g @ Z.T) / N - np.diag((1 - g ** 2).mean(1)) @ V
    u, _, vt = np.linalg.svd(Vn)
    Vn = u @ vt                                            # re-orthonormalise the rows
    done = np.max(np.abs(np.abs(np.diag(Vn @ V.T)) - 1)) < 1e-10
    V = Vn
    if done:
        break
Y = V @ Z

def absr(A):                                               # best |r| of each row with any source
    R = np.corrcoef(np.vstack([A, S]))[:2, 2:]
    return np.abs(R).max(1)

def kurt(v):
    v = (v - v.mean()) / v.std()
    return (v ** 4).mean() - 3

fig = plt.figure(figsize=(8.2, 6.4))
gs = fig.add_gridspec(2, 4, height_ratios=[1, 1.05])
panels = [(S, "(a) sources", "#5e5e54"),
          (Xc, "(b) observed mixtures", "#5e5e54"),
          (Z, f"(c) PCA + whitening\n|r| {absr(Z).min():.2f}–{absr(Z).max():.2f}", "#5e5e54"),
          (Y, f"(d) ICA\n|r| ≥ {absr(Y).min():.3f}", "#e8531d")]
for k, (A, title, col) in enumerate(panels):
    ax = fig.add_subplot(gs[0, k])
    ax.scatter(A[0], A[1], s=4, color=col, alpha=0.6)
    lim = np.abs(A).max() * 1.08
    ax.set_xlim(-lim, lim); ax.set_ylim(-lim, lim); ax.set_aspect("equal")
    ax.set_xticks([]); ax.set_yticks([])
    ax.set_title(title, fontsize=9)

# --- kurtosis of the whitened projection, direction by direction ---
ang = np.linspace(0, np.pi, 181)
k_unif = [kurt(np.cos(a) * Z[0] + np.sin(a) * Z[1]) for a in ang]
G = rng.normal(size=(2, N))
k_gaus = [kurt(np.cos(a) * G[0] + np.sin(a) * G[1]) for a in ang]
ax = fig.add_subplot(gs[1, :])
ax.plot(np.degrees(ang), k_unif, color="#161613", lw=2, label="whitened uniform mixture")
ax.plot(np.degrees(ang), k_gaus, color="#8a8a7e", lw=2, label="Gaussian data")
for i, d in enumerate(np.degrees(np.arctan2(V[:, 1], V[:, 0])) % 180):
    ax.axvline(d, color="#e8531d", ls="--", lw=1.4, label="ICA directions" if i == 0 else None)
ax.axhline(-1.2, color="#b7b6a8", lw=1, ls=":")
ax.text(2, -1.17, "uniform: −1.2", fontsize=8, color="#5e5e54")
ax.axhline(0, color="#b7b6a8", lw=1, ls=":")
ax.text(2, 0.03, "Gaussian: 0", fontsize=8, color="#5e5e54")
ax.set_xlim(0, 180); ax.set_ylim(-1.4, 0.55)
ax.set_xlabel("direction of projection (degrees)")
ax.set_ylabel("excess kurtosis")
ax.legend(loc="upper left", bbox_to_anchor=(0.29, 1.0), fontsize=8, frameon=False)
fig.tight_layout()
plt.show()

Two things in the bottom panel carry the argument. The Gaussian curve is flat: no direction is special, which is the rotation problem. The uniform curve has two clear dips, one for each source, and ICA’s directions land within a few degrees of them (excess kurtosis −1.22 and −1.18 there), even though the algorithm never computed kurtosis. ICA used \log\cosh, a different measure of non-Gaussianity that peaks at the same angles. A side observation from our simulation: the raw mixtures are closer to Gaussian (excess kurtosis −0.89 and −0.92) than either source (−1.19 and −1.22). Adding independent things together pushes toward the bell curve, the intuition of the central limit theorem. Searching for the least Gaussian directions undoes the mixing.

Sparse coding: a few parts from a large dictionary

Now make the non-Gaussian prior one that favours zeros, such as the Laplace, and drop the requirement that W be orthogonal. Each observation is then approximated as a sparse combination of the columns of W, and which columns are active changes from one observation to the next. This is sparse coding. W is now called a dictionary and each column an atom. Because only a few atoms are active for any one observation, the dictionary can be larger than the data dimension (L > D), which is called an overcomplete representation. (Murphy 2012)

The dictionary can be fixed, often a wavelet or cosine basis, since many natural signals are well approximated by a few such functions. Or it can be learned. (Murphy 2012) Learning it exactly means integrating over every z_i, which is hard, so in practice each z_i is replaced by its single best value. With a Laplace prior the objective becomes a familiar one: squared reconstruction error plus an \ell_1 penalty on each observation’s factors. (Murphy 2012) Two details make it work:

  • Constrain the atoms. Without a limit, W can grow while z shrinks, which lowers the penalty without changing the fit. So each atom’s length is capped at 1. (Murphy 2012)
  • Alternate. With W fixed, finding each z_i is exactly a lasso problem. With Z fixed, finding W is least squares. Alternating between the two is the obvious scheme. Mumford (1994) called this an analysis–synthesis loop. (Murphy 2012)

Variations

  • Non-negative matrix factorisation (NMF) (Paatero & Tapper 1994; Lee & Seung 2001) drops the penalty and requires both W and z to be non-negative. It has no hyperparameters to tune. The hope is interpretability: a positive sum of positive “parts” rather than a sparse sum of atoms that can cancel each other. Adding a sparsity prior on top gives non-negative sparse coding (Hoyer 2004). (Murphy 2012)
  • Sparse matrix factorisation makes both the factors and the dictionary sparse. Mairal et al.
    1. use an elastic-net style constraint on the atoms. Group or fused lasso penalties can replace the plain lasso. (Murphy 2012)
  • Bayesian sparse coding (Zhou et al. 2009) uses an on/off mask for each factor, with a beta process prior that lets the dictionary size be unbounded instead of fixed in advance. The effective dictionary shrinks as the noise rises, an instance of the Bayesian Occam’s razor met in automatic relevance determination, and this guards against overfitting. (Murphy 2012)

The visual cortex result

Much of the interest in sparse coding comes from one finding. Learn a dictionary from small patches of natural images and the atoms look like bar and edge detectors, the filters found in the simple cells of the primary visual cortex (Olshausen & Field 1996). In Murphy’s example, the penalty was set so that about 10 atoms are active per patch. ICA gives visually similar filters. PCA on the same patches gives sinusoidal gratings instead, which do not resemble cortical responses. That has led to the conjecture that parts of the cortex perform sparse coding of what we see. (Murphy 2012)

The PCA result has a clean explanation. The covariance between two pixels in natural images depends only on how far apart they are, not where they sit. For a covariance with that property, the eigenvectors are always sinusoids, so PCA rediscovers the Fourier basis. (Murphy 2012) In other words, PCA’s components were determined by a symmetry of the covariance, not by anything specific to images. Edges show up only once you look beyond the covariance, through non-Gaussianity or sparsity.

What it is good for

Murphy is frank that “it is interesting to look at the dictionaries learned by sparse coding, it is not necessarily very useful”. (Murphy 2012) The practical payoffs come from reconstruction.

  • Compressed sensing. Suppose you observe not x but a few linear projections of it, y = Rx + \epsilon, with far fewer measurements than dimensions. In an MRI scanner, each beam direction is one row of R. Recovering x looks impossible, but it is not if x has a sparse representation in a suitable dictionary. The answer is Bayesian inference with a sparse prior. It only works if the basis is right; otherwise the signal is not sparse. A dictionary learned for the domain beats a standard wavelet basis, and R is often chosen at random. (Murphy 2012)
  • Inpainting and denoising. To remove scratches or overlaid text from a photograph, cut it into overlapping patches, treat the damaged pixels as hidden and the rest as observed, and predict the hidden ones from a dictionary learned either from other images or from the undamaged patches of this one. Murphy’s example, from Mairal et al. (2008), learned 256 atoms from 7 million undamaged 12 × 12 colour patches of a 12-megapixel image. (Murphy 2012)

For a social scientist the lesson travels further than the applications. Interpretability of latent factors is bought with an assumption. PCA’s components are orthogonal and ordered because of how PCA is defined, not because the world is built that way. Rotate them by hand and you are choosing what to believe. Assume non-Gaussian or sparse factors and the data will pick the rotation, but only if the assumption is true. In any of these cases the factors describe structure in X; they are not causes.

Common pitfalls

WarningWhere this goes wrong

  • Running ICA on Gaussian-looking data. If the sources really are close to Gaussian, the rotation is not identified and the components ICA returns are one arbitrary rotation among many. Check the marginal distributions first. (Murphy 2012)

  • Reading the order, sign or size of ICA components. ICA recovers sources only up to permutation and sign, fixes each source’s variance at 1, and has no ranking like PCA’s “first component explains most”. Component 1 is not more important than component 2. (Murphy 2012)

  • Skipping centring and whitening. The standard algorithms assume both. Whitening is what reduces the problem to finding a rotation. (Murphy 2012)

  • Trusting one run. The ICA and dictionary-learning objectives are not convex. Different starting points can give different answers; compare several. (Murphy 2012)

  • Confusing sparse coding with sparse PCA. Sparse coding makes each observation use few factors; sparse PCA makes each factor use few variables. They answer different questions. (Murphy 2012)

  • Mistaking a pretty dictionary for a finding. Edge-like atoms are a striking result, but Murphy himself notes that a learned dictionary is not necessarily useful in itself. Judge the method by what it reconstructs or predicts. (Murphy 2012)

  • More sources than sensors. ICA needs a square mixing matrix. With fewer measurements than sources, there is no unique answer to recover. (Murphy 2012)

  • Treating components as causes. A recovered source is a statistical decomposition of X, not a mechanism. The causal questions need a design.

Appendix · the mathematics

The rotation problem. Let z \sim N(0, I) and x = Wz. For any orthogonal R (R^\top R = I), z' = Rz is also N(0, I), and x = (WR^\top) z'. Both (W, z) and (WR^\top, z') give \operatorname{cov}(x) = WW^\top, so a Gaussian likelihood cannot distinguish them. A non-Gaussian p(z) = \prod_j p_j(z_j) is generally not rotation-invariant, which breaks the tie. (Murphy 2012)

Whitening forces orthogonality. If the centred data are whitened so that E[xx^\top] = I, then in the noise-free model I = W E[zz^\top] W^\top = WW^\top, so W is orthogonal. That leaves D(D-1)/2 free parameters instead of D^2. (Murphy 2012)

The likelihood. Write V = W^{-1} (the recognition weights; W is the generative one). By the change-of-variables formula, p_x(x_t) = p_z(Vx_t)\,|\det V|, so for T independent draws \frac{1}{T}\log p(\mathcal D \mid V) = \log|\det V| + \frac{1}{T}\sum_{j=1}^{L}\sum_{t=1}^{T}\log p_j(v_j^\top x_t). With V orthogonal, |\det V| = 1, so maximising the likelihood is minimising \sum_j E[G_j(v_j^\top x)] with G_j = -\log p_j, subject to the rows of V being orthonormal. (Murphy 2012)

In plain words: after whitening, find the rotation under which each output coordinate looks as much like a draw from the assumed non-Gaussian source as possible.

FastICA. For one component with g = G', maximising E[G(v^\top x)] subject to v^\top v = 1 has Lagrangian gradient E[x\,g(v^\top x)] - \beta v and Hessian E[xx^\top g'(v^\top x)] - \beta I. Approximating E[xx^\top g'(v^\top x)] \approx E[xx^\top]E[g'(v^\top x)] = E[g'(v^\top x)]\,I makes the Hessian diagonal, and the Newton step simplifies to v^* = E[x\,g(v^\top x)] - E[g'(v^\top x)]\,v, \qquad v_{\text{new}} = v^*/\|v^*\|. Convergence is judged by |v^\top v_{\text{new}}| \to 1, because the sign of v may flip. Several components are updated together and the rows of V re-orthogonalised. (Murphy 2012) (In Figure 1 we do this through the SVD: the updated matrix \tilde V = P\Sigma Q^\top is replaced by PQ^\top, the nearest orthogonal matrix.)

Kurtosis and skewness. With \mu_k = E[(X - E X)^k], excess kurtosis is \operatorname{kurt} = \mu_4/\sigma^4 - 3 (0 for a Gaussian; −1.2 for a uniform; +3 for a Laplace) and skewness is \mu_3/\sigma^3. Unit-variance log densities: Laplace, \log p(z) = -\sqrt2|z| - \log\sqrt2; logistic, \log p(z) = -2\log\cosh\!\big(\tfrac{\pi}{2\sqrt3}z\big) - \log\tfrac{4\sqrt3}{\pi}. (Murphy 2012)

Three roads to the same objective. (i) Negentropy, H(N(\mu,\sigma^2)) - H(z), is non-negative because the Gaussian has the largest entropy for a given variance. For whitened data and orthogonal V each z_j has unit variance, so maximising total negentropy is minimising \sum_j H(z_j), which is the likelihood objective. (ii) The multi-information I(z) = \sum_j H(z_j) - H(z) measures dependence; H(Vx) = H(x) for orthogonal V, so minimising it is again minimising \sum_j H(z_j). (iii) Infomax: for outputs y_j = \phi(v_j^\top x) + \epsilon, H(y) \approx \sum_j E[\log \phi'(v_j^\top x)] + \log|\det V|; if \phi is a CDF, \phi' is a density and this is the log-likelihood. (Murphy 2012)

Sparse coding. The marginal likelihood \sum_i \log\int N(x_i \mid Wz_i, \sigma^2 I)p(z_i)\,dz_i is replaced by \sum_i \max_{z_i}[\log N(x_i \mid Wz_i, \sigma^2 I) + \log p(z_i)]. With a Laplace prior this gives \min_{W \in \mathcal C,\, Z}\ \sum_{i=1}^{N} \tfrac12\|x_i - Wz_i\|_2^2 + \lambda\|z_i\|_1, \qquad \mathcal C = \{W : w_j^\top w_j \le 1 \text{ for every column } j\}. For fixed W each z_i is a lasso; for fixed Z, W is constrained least squares. (Murphy 2012) If the dictionary happens to be orthonormal, the lasso step has a closed form, the soft threshold z_{ij} = \operatorname{sign}(w_j^\top x_i)\max(|w_j^\top x_i| - \lambda, 0) (standard; see regularization). Tiny case: with the identity dictionary, x = (3, 0.2) and \lambda = 0.5 give z = (2.5, 0); the small coordinate is switched off.

NMF and sparse MF. NMF solves \min \tfrac12\sum_i\|x_i - Wz_i\|_2^2 subject to W \ge 0, z_i \ge 0. Sparse matrix factorisation adds \lambda\|z_i\|_1 and constrains each atom by \|w_j\|_2^2 + \gamma\|w_j\|_1 \le 1. (Murphy 2012)

Compressed sensing. Observe y = Rx + \epsilon with R an M \times D sensing matrix, M \ll D. Assume x = Wz with z sparse, and infer p(x \mid y, R). Inpainting is the special case where R selects patches and the unknown pixels are inferred from p(y_H \mid y_V, \theta). (Murphy 2012)

## Why it matters

[PCA and factor analysis](unsupervised-learning.qmd) model each observation as a weighted sum of a few
hidden factors. Both assume the factors are Gaussian, and that assumption has a cost which applied
researchers meet as the **rotation problem**: the model identifies the space the factors span, but not
a unique set of axes inside it. Factor analysts handle this by picking a rotation (varimax and its
relatives) that is easy to interpret. Murphy's point is that ICA is the same move made principled: once
the factors are non-Gaussian, the data themselves say which rotation is right. [@murphy_ml]

The family matters for three reasons. First, it shows exactly which assumption makes latent factors
**identifiable**. That question comes back in [factor analysis](../03-regression/factor-analysis.qmd),
[structural equation models](../03-regression/structural-equation-models.qmd) and
[matrix factorisation](matrix-factorization-and-recommenders.qmd). Second, it carries the
[lasso's](../04-predictive/regularization.qmd) sparsity idea from supervised to **unsupervised**
learning: instead of a few non-zero coefficients, a few active factors per observation. Third, it has
some of machine learning's best-known results: a model of how the visual cortex might encode images, and
compressed sensing, which reconstructs an MRI scan from fewer measurements than pixels. [@murphy_ml]

## One model, many priors {#sec-family}

Every method here starts from the same equation. An observed vector $x$ (the readings at $D$ sensors,
or $D$ variables for one respondent) is a weighted sum of $L$ hidden factors $z$, plus noise:
$x = Wz + \epsilon$. The columns of $W$ are the **loadings** (or, below, the *atoms* of a
*dictionary*). The methods differ only in what they assume about $z$, about $W$, and about whether $W$'s
columns must be orthogonal. Murphy collects them in one table: [@murphy_ml]

| Method | Prior on the factors $z$ | Prior on the loadings $W$ | $W$ orthogonal? |
|---|---|---|---|
| PCA | Gaussian | none (estimated) | yes |
| Factor analysis | Gaussian | none | no |
| **ICA** | **non-Gaussian** | none | yes |
| **Sparse coding** | **Laplace** (sparse) | none | no |
| Sparse PCA | Gaussian | Laplace (sparse) | maybe |
| Sparse matrix factorisation | Laplace | Laplace | no |

Read the table by its rows. ICA changes one cell of PCA's row. Sparse coding takes ICA's
non-Gaussian factor prior, picks one that favours zeros, and drops the orthogonality. Sparse PCA puts
the sparsity in a different place: on the *loadings* rather than the factors. Murphy warns against
confusing the two. [@murphy_ml] NMF, below, replaces priors with a sign constraint.

## The cocktail party: ICA {#sec-ica}

Murphy opens with the **cocktail party problem**. Several people talk at once in a crowded room. Your
two ears are two microphones, and each picks up a different linear mixture of the voices. The task is to
recover the separate voices from the mixtures. This is **blind source separation**: "blind" because you
know nothing about the sources except that they were mixed. It arises in audio, in EEG and MEG brain
recordings, in financial data, and in any dataset where hidden sources are mixed together linearly.
[@murphy_ml] The model is $x_t = Wz_t$, where $W$ is now called the **mixing matrix** and each
$z_t$ holds the sources at time $t$. Each time point is treated as an independent draw; ICA ignores the
order. [@murphy_ml]

### Why PCA cannot do it {#sec-why-pca-fails}

PCA assumes each source is an independent standard Gaussian. A cloud of independent standard Gaussians
is perfectly round, and a round cloud looks the same after any rotation. So if $(W, z)$ explains the
data, so does $(WR^\top, Rz)$ for any rotation $R$, and the likelihood cannot tell them apart. PCA finds
the best linear subspace, but it "cannot uniquely recover the signals themselves". [@murphy_ml]

Murphy's two-dimensional demonstration makes this visible. Take two independent sources, each uniform
(so their joint distribution is a square), and mix them with
$W = \left(\begin{smallmatrix}2 & 3\\ 2 & 1\end{smallmatrix}\right)$. The square becomes a slanted
parallelogram. PCA followed by rescaling, a step called **whitening**, turns the parallelogram back into
a square of the right size, but tilted at an arbitrary angle. A Gaussian contains no information about
which angle to rotate back by. In Murphy's phrase, PCA solves "half" of the problem: it finds the
subspace, and ICA's only remaining job is to find the rotation. [@murphy_ml] @fig-ica rebuilds the
demonstration.

### What ICA assumes instead {#sec-non-gaussian}

ICA keeps the independence of the sources and drops the bell shape: each source may have any
non-Gaussian distribution, with variance fixed at 1 so that scale lives in $W$. [@murphy_ml] Murphy
names three ways to be non-Gaussian, measured by **kurtosis** (how peaked and heavy-tailed a
distribution is, relative to a Gaussian) and **skewness** (how lopsided it is): [@murphy_ml]

- **Super-Gaussian** (positive excess kurtosis): a sharp spike at the mean and heavy tails. The Laplace
  distribution is the classic case. Natural signals such as images and speech, passed through certain
  linear filters, look like this.
- **Sub-Gaussian** (negative excess kurtosis): flatter than a Gaussian. The uniform distribution is the
  classic case.
- **Skewed**: asymmetric, like the gamma distribution.

In practice the exact source shape matters less than you might fear. When ICA is fitted by maximum
likelihood, it is "not critical" to know the exact source distribution, but it is important to know
whether it is sub- or super-Gaussian; a smooth stand-in such as $\log\cosh$ is commonly used.
[@murphy_ml]

What ICA gives back is the sources **up to permutation and sign**: it cannot know which voice you called
"first", nor whether a source was recorded upside down. [@murphy_ml] It also needs as many sensors as
sources ($W$ square). With more sources than sensors, the sources cannot be recovered uniquely; the best
you can do is a posterior over them. [@murphy_ml]

### How it is fitted {#sec-fitting}

The standard route is to centre and whiten the data first. After whitening, the remaining unmixing
matrix must be orthogonal: a pure rotation. In $D$ dimensions this cuts the unknowns from $D^2$ to
$D(D-1)/2$. In two dimensions that leaves a single angle. [@murphy_ml] Then:

- **FastICA** (Hyvärinen & Oja) is an approximate Newton method. Each update is cheap, the directions
  are renormalised after every step, and convergence is checked on the direction rather than the sign.
  The objective is not convex, so there are several local optima. FastICA uses them: it finds several
  components at once and keeps them orthogonal. Unlike PCA, the components have no natural order; the
  first is not "more important" than the second. [@murphy_ml]
- **EM with flexible sources.** Instead of fixing a source shape, model each source as a
  [mixture of Gaussians](mixture-models-and-em.qmd) and alternate between estimating the source
  densities and the mixing matrix. Murphy cites Moulines et al. (1997) and Attias (1999) for this
  *independent factor analysis* model. [@murphy_ml]

Murphy then shows that three other ways of motivating ICA all lead back to maximum likelihood once the
data are whitened and the unmixing is orthogonal: making the components as **non-Gaussian** as possible
(through *negentropy*, a cousin of projection pursuit), making them as **independent** as possible
(minimising mutual information), and maximising the **information flow** through a simple neural network
(*infomax*, Bell & Sejnowski 1995). [@murphy_ml] The [appendix](#sec-math) gives the short argument.

uniform sources, mixed by his matrix $W$. The top row follows the data through PCA and ICA. The bottom
panel shows *why* ICA can find the right angle: it measures the kurtosis of the whitened data projected
on every direction.

#| label: fig-ica
#| fig-cap: "Why PCA solves only half the problem (our simulation after Murphy's Figure 12.21; 500 draws). Top, left to right: two independent uniform sources form a square; mixing by W = [[2, 3], [2, 1]] shears it into a parallelogram; PCA plus whitening restores a square but at an arbitrary tilt (even the best-matching source correlates only |r| 0.73 and 0.78 with the two PCA axes); ICA (FastICA, log cosh, written by hand) finds the rotation and recovers both sources (|r| ≥ 0.998 after the sign and order are matched). Bottom: excess kurtosis of the whitened data projected onto each direction. import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(7)
N = 500
S = rng.uniform(-np.sqrt(3), np.sqrt(3), size=(2, N))   # unit-variance uniform sources
W = np.array([[2.0, 3.0], [2.0, 1.0]])                   # Murphy's mixing matrix (eq 12.98)
X = W @ S

# --- PCA + whitening: rotate to the eigenvectors, rescale each axis to unit variance ---
Xc = X - X.mean(1, keepdims=True)
vals, vecs = np.linalg.eigh(np.cov(Xc))
Z = np.diag(vals ** -0.5) @ vecs.T @ Xc

# --- symmetric FastICA with G(u) = log cosh u, so g = tanh and g' = 1 - tanh^2 ---
V = np.linalg.qr(rng.normal(size=(2, 2)))[0]
for _ in range(200):
    Y = V @ Z
    g = np.tanh(Y)
    Vn = (g @ Z.T) / N - np.diag((1 - g ** 2).mean(1)) @ V
    u, _, vt = np.linalg.svd(Vn)
    Vn = u @ vt                                            # re-orthonormalise the rows
    done = np.max(np.abs(np.abs(np.diag(Vn @ V.T)) - 1)) < 1e-10
    V = Vn
    if done:
        break
Y = V @ Z

def absr(A):                                               # best |r| of each row with any source
    R = np.corrcoef(np.vstack([A, S]))[:2, 2:]
    return np.abs(R).max(1)

def kurt(v):
    v = (v - v.mean()) / v.std()
    return (v ** 4).mean() - 3

fig = plt.figure(figsize=(8.2, 6.4))
gs = fig.add_gridspec(2, 4, height_ratios=[1, 1.05])
panels = [(S, "(a) sources", "#5e5e54"),
          (Xc, "(b) observed mixtures", "#5e5e54"),
          (Z, f"(c) PCA + whitening\n|r| {absr(Z).min():.2f}–{absr(Z).max():.2f}", "#5e5e54"),
          (Y, f"(d) ICA\n|r| ≥ {absr(Y).min():.3f}", "#e8531d")]
for k, (A, title, col) in enumerate(panels):
    ax = fig.add_subplot(gs[0, k])
    ax.scatter(A[0], A[1], s=4, color=col, alpha=0.6)
    lim = np.abs(A).max() * 1.08
    ax.set_xlim(-lim, lim); ax.set_ylim(-lim, lim); ax.set_aspect("equal")

    ax.set_title(title, fontsize=9)

ang = np.linspace(0, np.pi, 181)

for i, d in enumerate(np.degrees(np.arctan2(V[:, 1], V[:, 0])) % 180):

ax.axhline(-1.2, color="#b7b6a8", lw=1, ls=":")
ax.text(2, -1.17, "uniform: −1.2", fontsize=8, color="#5e5e54")

ax.text(2, 0.03, "Gaussian: 0", fontsize=8, color="#5e5e54")
ax.set_xlim(0, 180); ax.set_ylim(-1.4, 0.55)
ax.set_xlabel("direction of projection (degrees)")
ax.set_ylabel("excess kurtosis")
ax.legend(loc="upper left", bbox_to_anchor=(0.29, 1.0), fontsize=8, frameon=False)

Two things in the bottom panel carry the argument. The Gaussian curve is flat: no direction is special,
which is the rotation problem. The uniform curve has two clear dips, one for each source, and ICA's
directions land within a few degrees of them (excess kurtosis −1.22 and −1.18 there), even though the algorithm never computed kurtosis. ICA used $\log\cosh$, a different measure of
non-Gaussianity that peaks at the same angles. A side observation from our simulation: the raw mixtures
are closer to Gaussian (excess kurtosis −0.89 and −0.92) than either source (−1.19 and −1.22). Adding
independent things together pushes toward the bell curve, the intuition of the
[central limit theorem](../02-inference/sampling-distributions-clt.qmd). Searching for the *least*
Gaussian directions undoes the mixing.

## Sparse coding: a few parts from a large dictionary {#sec-sparse-coding}

Now make the non-Gaussian prior one that favours zeros, such as the Laplace, and drop the requirement
that $W$ be orthogonal. Each observation is then approximated as a **sparse** combination of the
columns of $W$, and which columns are active changes from one observation to the next. This is **sparse
coding**. $W$ is now called a **dictionary** and each column an **atom**. Because only a few atoms are
active for any one observation, the dictionary can be larger than the data dimension ($L > D$), which is
called an **overcomplete** representation. [@murphy_ml]

The dictionary can be **fixed**, often a wavelet or cosine basis, since many natural signals are
well approximated by a few such functions. Or it can be **learned**. [@murphy_ml] Learning it exactly
means integrating over every $z_i$, which is hard, so in practice each $z_i$ is replaced by its single
best value. With a Laplace prior the objective becomes a familiar one: squared reconstruction error
plus an $\ell_1$ penalty on each observation's factors. [@murphy_ml] Two details make it work:

- **Constrain the atoms.** Without a limit, $W$ can grow while $z$ shrinks, which lowers the penalty
  without changing the fit. So each atom's length is capped at 1. [@murphy_ml]
- **Alternate.** With $W$ fixed, finding each $z_i$ is exactly a [lasso](../04-predictive/regularization.qmd)
  problem. With $Z$ fixed, finding $W$ is least squares. Alternating between the two is the obvious
  scheme. Mumford (1994) called this an *analysis–synthesis loop*. [@murphy_ml]

### Variations {#sec-variations}

- **Non-negative matrix factorisation (NMF)** (Paatero & Tapper 1994; Lee & Seung 2001) drops the
  penalty and requires both $W$ and $z$ to be non-negative. It has no hyperparameters to tune. The hope
  is interpretability: a positive sum of positive "parts" rather than a sparse sum of atoms that can
  cancel each other. Adding a sparsity prior on top gives *non-negative sparse coding* (Hoyer 2004).
  [@murphy_ml]
- **Sparse matrix factorisation** makes both the factors and the dictionary sparse. Mairal et al.
  (2010) use an elastic-net style constraint on the atoms. Group or fused lasso penalties can replace
  the plain lasso. [@murphy_ml]
- **Bayesian sparse coding** (Zhou et al. 2009) uses an on/off mask for each factor, with a beta
  process prior that lets the dictionary size be unbounded instead of fixed in advance. The effective
  dictionary shrinks as the noise rises, an instance of the Bayesian Occam's razor met in
  [automatic relevance determination](automatic-relevance-determination.qmd), and this guards against
  overfitting. [@murphy_ml]

### The visual cortex result {#sec-cortex}

Much of the interest in sparse coding comes from one finding. Learn a dictionary from small patches of
natural images and the atoms look like bar and edge detectors, the filters found in the **simple cells
of the primary visual cortex** (Olshausen & Field 1996). In Murphy's example, the penalty was set so
that about 10 atoms are active per patch. ICA gives visually similar filters. PCA on the same patches
gives sinusoidal gratings instead, which do not resemble cortical responses. That has led to the
conjecture that parts of the cortex perform sparse coding of what we see. [@murphy_ml]

The PCA result has a clean explanation. The covariance between two pixels in natural images depends
only on how far apart they are, not where they sit. For a covariance with that property, the
eigenvectors are always sinusoids, so PCA rediscovers the Fourier basis. [@murphy_ml] In other words,
PCA's components were determined by a symmetry of the covariance, not by anything specific to
images. Edges show up only once you look beyond the covariance, through non-Gaussianity or sparsity.

## What it is good for {#sec-uses}

Murphy is frank that "it is interesting to look at the dictionaries learned by sparse coding, it is not
necessarily very useful". [@murphy_ml] The practical payoffs come from reconstruction.

- **Compressed sensing.** Suppose you observe not $x$ but a few linear projections of it,
  $y = Rx + \epsilon$, with far fewer measurements than dimensions. In an MRI scanner, each beam
  direction is one row of $R$. Recovering $x$ looks impossible, but it is not if $x$ has a sparse
  representation in a suitable dictionary. The answer is Bayesian inference with a sparse prior. It only
  works if the basis is right; otherwise the signal is not sparse. A dictionary learned for the domain
  beats a standard wavelet basis, and $R$ is often chosen at random. [@murphy_ml]
- **Inpainting and denoising.** To remove scratches or overlaid text from a photograph, cut it into
  overlapping patches, treat the damaged pixels as hidden and the rest as observed, and predict the hidden
  ones from a dictionary learned either from other images or from the undamaged patches of this one.
  Murphy's example, from Mairal et al. (2008), learned 256 atoms from 7 million undamaged 12 × 12 colour
  patches of a 12-megapixel image. [@murphy_ml]

For a social scientist the lesson travels further than the applications. **Interpretability of latent
factors is bought with an assumption.** PCA's components are orthogonal and ordered because of how PCA
is defined, not because the world is built that way. Rotate them by hand and you are choosing what to
believe. Assume non-Gaussian or sparse factors and the data will pick the rotation, but only if the
assumption is true. In any of these cases the factors describe structure in $X$; they are not causes.

## Common pitfalls

::: {.callout-warning title="Where this goes wrong"}

- **Running ICA on Gaussian-looking data.** If the sources really are close to Gaussian, the rotation is
  not identified and the components ICA returns are one arbitrary rotation among many. Check the
  marginal distributions first. [@murphy_ml]

- **Reading the order, sign or size of ICA components.** ICA recovers sources only up to permutation
  and sign, fixes each source's variance at 1, and has no ranking like PCA's "first component explains
  most". Component 1 is not more important than component 2. [@murphy_ml]

- **Skipping centring and whitening.** The standard algorithms assume both. Whitening is what reduces
  the problem to finding a rotation. [@murphy_ml]

- **Trusting one run.** The ICA and dictionary-learning objectives are not convex. Different starting
  points can give different answers; compare several. [@murphy_ml]

- **Confusing sparse coding with sparse PCA.** Sparse coding makes each observation use few factors;
  sparse PCA makes each factor use few variables. They answer different questions. [@murphy_ml]

- **Mistaking a pretty dictionary for a finding.** Edge-like atoms are a striking result, but Murphy
  himself notes that a learned dictionary is not necessarily useful in itself. Judge the method by what it
  reconstructs or predicts. [@murphy_ml]

- **More sources than sensors.** ICA needs a square mixing matrix. With fewer measurements than sources,
  there is no unique answer to recover. [@murphy_ml]

- **Treating components as causes.** A recovered source is a statistical decomposition of $X$, not a
  mechanism. The [causal questions](../05-causal-inference/index.qmd) need a design.

:::

## Appendix · the mathematics {#sec-math .unnumbered}

::: {.math-appendix}

**The rotation problem.** Let $z \sim N(0, I)$ and $x = Wz$. For any orthogonal $R$ ($R^\top R = I$),
$z' = Rz$ is also $N(0, I)$, and $x = (WR^\top) z'$. Both $(W, z)$ and $(WR^\top, z')$ give
$\operatorname{cov}(x) = WW^\top$, so a Gaussian likelihood cannot distinguish them. A non-Gaussian
$p(z) = \prod_j p_j(z_j)$ is generally not rotation-invariant, which breaks the tie. [@murphy_ml]

**Whitening forces orthogonality.** If the centred data are whitened so that $E[xx^\top] = I$, then in
the noise-free model $I = W E[zz^\top] W^\top = WW^\top$, so $W$ is orthogonal. That leaves
$D(D-1)/2$ free parameters instead of $D^2$. [@murphy_ml]

**The likelihood.** Write $V = W^{-1}$ (the *recognition* weights; $W$ is the *generative* one). By the
change-of-variables formula, $p_x(x_t) = p_z(Vx_t)\,|\det V|$, so for $T$ independent draws
$$
\frac{1}{T}\log p(\mathcal D \mid V) = \log|\det V| + \frac{1}{T}\sum_{j=1}^{L}\sum_{t=1}^{T}\log p_j(v_j^\top x_t).
$$
With $V$ orthogonal, $|\det V| = 1$, so maximising the likelihood is minimising
$\sum_j E[G_j(v_j^\top x)]$ with $G_j = -\log p_j$, subject to the rows of $V$ being orthonormal.
[@murphy_ml]

> **In plain words:** after whitening, find the rotation under which each output coordinate looks as
> much like a draw from the assumed non-Gaussian source as possible.

**FastICA.** For one component with $g = G'$, maximising $E[G(v^\top x)]$ subject to $v^\top v = 1$ has
Lagrangian gradient $E[x\,g(v^\top x)] - \beta v$ and Hessian $E[xx^\top g'(v^\top x)] - \beta I$.
Approximating $E[xx^\top g'(v^\top x)] \approx E[xx^\top]E[g'(v^\top x)] = E[g'(v^\top x)]\,I$ makes the
Hessian diagonal, and the Newton step simplifies to
$$
v^* = E[x\,g(v^\top x)] - E[g'(v^\top x)]\,v, \qquad v_{\text{new}} = v^*/\|v^*\|.
$$
Convergence is judged by $|v^\top v_{\text{new}}| \to 1$, because the sign of $v$ may flip. Several
components are updated together and the rows of $V$ re-orthogonalised. [@murphy_ml] (In @fig-ica we do this through the SVD: the updated matrix
$\tilde V = P\Sigma Q^\top$ is replaced by $PQ^\top$, the nearest orthogonal matrix.)

**Kurtosis and skewness.** With $\mu_k = E[(X - E X)^k]$, excess kurtosis is
$\operatorname{kurt} = \mu_4/\sigma^4 - 3$ (0 for a Gaussian; −1.2 for a uniform; +3 for a Laplace)
and skewness is $\mu_3/\sigma^3$. Unit-variance log densities: Laplace,
$\log p(z) = -\sqrt2|z| - \log\sqrt2$; logistic, $\log p(z) = -2\log\cosh\!\big(\tfrac{\pi}{2\sqrt3}z\big)
- \log\tfrac{4\sqrt3}{\pi}$. [@murphy_ml]

**Three roads to the same objective.** (i) *Negentropy*, $H(N(\mu,\sigma^2)) - H(z)$, is non-negative
because the Gaussian has the largest entropy for a given variance. For whitened data and orthogonal $V$
each $z_j$ has unit variance, so maximising total negentropy is minimising $\sum_j H(z_j)$, which is
the likelihood objective. (ii) The *multi-information* $I(z) = \sum_j H(z_j) - H(z)$ measures dependence;
$H(Vx) = H(x)$ for orthogonal $V$, so minimising it is again minimising $\sum_j H(z_j)$. (iii)
*Infomax*: for outputs $y_j = \phi(v_j^\top x) + \epsilon$, $H(y) \approx \sum_j E[\log \phi'(v_j^\top x)]
+ \log|\det V|$; if $\phi$ is a CDF, $\phi'$ is a density and this is the log-likelihood. [@murphy_ml]

**Sparse coding.** The marginal likelihood $\sum_i \log\int N(x_i \mid Wz_i, \sigma^2 I)p(z_i)\,dz_i$ is
replaced by $\sum_i \max_{z_i}[\log N(x_i \mid Wz_i, \sigma^2 I) + \log p(z_i)]$. With a Laplace prior
this gives
$$
\min_{W \in \mathcal C,\, Z}\ \sum_{i=1}^{N} \tfrac12\|x_i - Wz_i\|_2^2 + \lambda\|z_i\|_1,
\qquad \mathcal C = \{W : w_j^\top w_j \le 1 \text{ for every column } j\}.
$$
For fixed $W$ each $z_i$ is a lasso; for fixed $Z$, $W$ is constrained least squares. [@murphy_ml] If
the dictionary happens to be orthonormal, the lasso step has a closed form, the soft threshold
$z_{ij} = \operatorname{sign}(w_j^\top x_i)\max(|w_j^\top x_i| - \lambda, 0)$ (standard; see
[regularization](../04-predictive/regularization.qmd)). Tiny case: with the identity dictionary,
$x = (3, 0.2)$ and $\lambda = 0.5$ give $z = (2.5, 0)$; the small coordinate is switched off.

**NMF and sparse MF.** NMF solves $\min \tfrac12\sum_i\|x_i - Wz_i\|_2^2$ subject to $W \ge 0$,
$z_i \ge 0$. Sparse matrix factorisation adds $\lambda\|z_i\|_1$ and constrains each atom by
$\|w_j\|_2^2 + \gamma\|w_j\|_1 \le 1$. [@murphy_ml]

**Compressed sensing.** Observe $y = Rx + \epsilon$ with $R$ an $M \times D$ sensing matrix, $M \ll D$.
Assume $x = Wz$ with $z$ sparse, and infer $p(x \mid y, R)$. Inpainting is the special case where $R$
selects patches and the unknown pixels are inferred from $p(y_H \mid y_V, \theta)$. [@murphy_ml]

:::
