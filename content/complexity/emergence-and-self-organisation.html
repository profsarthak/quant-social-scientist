Emergence & Self-Organisation

  • Show All Code
  • Hide All Code
  • View Source

The central idea of complexity: large-scale order that no part contains and no one designed, arising from simple local rules — and the unsettling gap between what individuals want and what societies become.

A single ant is nearly mindless; an ant colony forages with collective intelligence. A neuron is not conscious; a brain is. Emergence is this leap — macroscopic pattern and behaviour arising from many simple parts following local rules, not present in or predictable from any part. Its social-science emblem is Schelling’s segregation model, where a mild individual preference produces stark collective segregation that no one intended — the defining lesson of the whole Dynamics cluster.

Why it matters

Emergence is why social aggregates can’t be read off individual intentions. Segregation without racists, bank runs without panic, traffic jams without crashes, inequality without villainy — the macro pattern is “disconnected from its origins” (Mitchell 2009). For a quantitative social scientist this is a standing warning: the representative-agent shortcut and the assumption that group outcomes mirror individual preferences can both be exactly wrong.

Emergence: “more is different”

Emergence occurs when large numbers of simple entities — each following local rules with no central leader — produce macroscopic patterns not present in, or predictable from, the parts (Mitchell 2009; Miller and Page 2007). The slogan is “more is different”: aggregate behaviour is “disconnected from its origins” (Mitchell 2009). The canonical examples (Mitchell 2009; Miller and Page 2007):

  • Ant colonies — coherent foraging fronts from simple chemical signals, no commander.
  • Brains — intelligence and consciousness from interactions of non-conscious neurons.
  • Markets — global prices from the chaotic, heterogeneous efforts of independent traders. (Grown from the bottom up, such a price is a statistical cloud around equilibrium, not a single number: see markets without an auctioneer.)
  • Traffic jams & segregation — collective patterns that appear even when no individual intends them.

Self-organisation

Self-organisation is the dynamical process by which a system spontaneously forms structure and order over time without a central controller or blueprint (Mitchell 2009). It is “collective intelligence” arising from local feedback — fireflies flashing in unison, the mutually sustaining structure of an economy (Mitchell 2009). (It is also Meadows’ high leverage point: a system that can build its own structure can adapt to almost anything.)

Schelling: mild preferences, stark segregation

The classic social-science demonstration (Miller and Page 2007). Agents of two types sit on a grid and move if the fraction of same-type neighbours falls below a threshold. The shock is how little intolerance it takes: agents content to be a minority — happy with, say, just a third of neighbours like themselves — still unravel an integrated city into stark segregation (Miller and Page 2007). It is the purest example of an “unintended collective outcome”: local preferences no one would call extreme aggregate into a macro pattern no individual sought (Miller and Page 2007).

Show the figure code 
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(2)
L, empty_frac, thresh = 50, 0.10, 0.35
cells = rng.choice([0, 1, 2], size=(L, L), p=[empty_frac, (1-empty_frac)/2, (1-empty_frac)/2])
grid0 = cells.copy()

def same_frac(g, i, j):
    t = g[i, j]
    if t == 0: return 1.0
    s = o = 0
    for di in (-1, 0, 1):
        for dj in (-1, 0, 1):
            if di == 0 and dj == 0: continue
            v = g[(i+di) % L, (j+dj) % L]
            if v != 0:
                o += 1; s += (v == t)
    return 1.0 if o == 0 else s/o

def seg_index(g):
    vals = [same_frac(g, i, j) for i in range(L) for j in range(L) if g[i, j] != 0]
    return np.mean(vals)

s0 = seg_index(cells)
for _ in range(40):
    moved = False
    empties = list(zip(*np.where(cells == 0)))
    order = rng.permutation(L*L)
    for idx in order:
        i, j = idx // L, idx % L
        if cells[i, j] != 0 and same_frac(cells, i, j) < thresh and empties:
            e = empties.pop(rng.integers(len(empties)))
            cells[e] = cells[i, j]; empties.append((i, j)); cells[i, j] = 0
            moved = True
    if not moved: break
s1 = seg_index(cells)

cmap = plt.matplotlib.colors.ListedColormap(["#f4f3ec", "#161613", "#8a8a7e"])
fig, (axL, axR) = plt.subplots(1, 2, figsize=(8.6, 4.4))
axL.imshow(grid0, cmap=cmap, vmin=0, vmax=2); axL.set_title(f"start: mixed (segregation {s0:.2f})"); axL.axis("off")
axR.imshow(cells, cmap=cmap, vmin=0, vmax=2); axR.set_title(f"end: segregated (segregation {s1:.2f})"); axR.axis("off")
fig.suptitle("Schelling: a 35% same-type preference produces near-total segregation", fontsize=11)
fig.tight_layout()
plt.show()

Schelling up close: tipping is not segregation

Miller and Page rebuild Schelling’s model in one dimension to take it apart, and the first thing they do is separate two words that are usually run together (Miller and Page 2007):

  • Tipping is a process: moves that trigger more moves. They measure it as the number of agents who eventually move relative to the number who wanted to move at the start.
  • Segregation is an outcome: how rarely the two types end up side by side. They count adjacent pairs (ignoring empty sites) of different types; fewer means more segregated.

Their world is a ring of 100 sites, each equally likely to hold an agent of type A, an agent of type B, or nobody. Each agent looks four sites each way and moves to a random empty site if too few of its neighbours are its own type. Averaged over 500 runs (Miller and Page 2007):

Thresholds (type A / type B) 40 / 40 30 / 50 31 / 49
Agents who initially want to move 19.2 26.0 19.8
Agents who move in the first round 21.9 30.1 23.2
Agents who move within 100 rounds 42.5 110.8 58.8
Mixed-type adjacencies at the end 5.8 5.0 5.8

Three lessons come out of this one table.

1. Little tipping can still mean a lot of segregation. With symmetric 40% thresholds only about twice as many agents move as wanted to at the start, yet mixed adjacencies fall from about 30 to 5.8. Making the thresholds asymmetric (30/50, closer to Schelling’s own set-up) roughly quadruples the movement but ends at about the same level of segregation. The extra movement comes almost entirely from the less tolerant type: 23 of the 29 first-round movers. With only one type doing the sorting, getting to a segregated state takes longer (Miller and Page 2007). Most of the cascades are “my neighbour left, so now I want to leave” rather than “the newcomer drove me out” (Miller and Page 2007).

2. Thresholds act in steps, not smoothly. An agent with eight neighbours can only see same-type shares of 0, 1/8, 2/8 and so on, so many different threshold values produce identical behaviour. Across neighbourhoods of two to eight agents there are 42 possible same-type counts, and a 40% rule and a 50% rule disagree on only two of them (2 of 5 and 3 of 7; our count confirms M&P’s figure) (Miller and Page 2007). That is why 31/49, which looks like a small change from 30/50, behaves like 40/40 instead.

NoteOur replication, and a boundary the book leaves implicit

We rebuilt the model by hand (ring of 100, four neighbours each side, share of occupied neighbours, location-ordered updating, 300 runs). The 40/40 column reproduces closely under the rule as stated, “move if the share is below the threshold”: 19.3 / 22.0 / 42.3 / 5.5 against the book’s 19.2 / 21.9 / 42.5 / 5.8. Under that strict rule, though, 30/50 and 31/49 would be identical, because no attainable share lies in [0.30, 0.31) or [0.49, 0.50). The book’s two asymmetric columns are reproduced only when agents also move at a share exactly equal to their threshold: we then get 25.9 / 29.5 / 138.7 / 5.1 for 30/50 and 19.8 / 22.9 / 59.0 / 5.4 for 31/49. On that reading, the whole difference between the two asymmetric columns is whether a 50% agent with exactly half same-type neighbours stays or goes. That supports M&P’s point about steps, and adds that which side of the boundary “exactly half” falls on can be the entire result.

3. The thresholds that drive tipping are the ones at 50%. High tipping goes with the 50% rule. Moves are positive feedback, and under the right conditions that feedback produces cascades that sweep the system (Miller and Page 2007).

Does the grid matter? Schelling on networks

Schelling used a checkerboard. Is the result an artefact of that geometry? Miller and Page rerun it on three networks in which every agent has eight neighbours (Miller and Page 2007). Loop: houses round a lake, four each side. Grid: Schelling’s eight surrounding squares. Pack: city blocks of eight in which even physically adjacent houses can belong to “different” neighbourhoods. Each network had 400 agents, half the sites occupied, a 40% threshold, and 500 trials:

Grid Loop Pack
Segregation (mean share of like-type neighbours at rest) 75% 78% 80%
Tipping (share of relocations set off by the initial moves) 14% 20% 31%

The grid understates segregation; it is the least segregating of the three. The ordering follows overlap, the average number of neighbours an agent shares with each of its neighbours. On M&P’s count it is 7.0 for the Pack, 6.5 for the Loop and 5.0 for the Grid. The more your neighbours are also each other’s neighbours, the more one departure unsettles the rest, so moves trigger further moves and like types gather together (Miller and Page 2007). The same overlap measure ordered conformity under majority rule. Miller and Page’s conclusion applies to both: in a “pinhead world” with no network, there is no segregation and majority rule gives total conformity. These results are easy to derive and tell you nothing (Miller and Page 2007).

Two kinds of emergence: disorganised and organised complexity

Miller and Page start their chapter on emergence with a warning and a theorem (Miller and Page 2007). The warning: much of the feeling of emergence is surprise, and surprise is close to ignorance. Planetary motion looked mysterious until Kepler showed it was an ellipse. The theorem: we already have a rigorous result about emergence, and every statistics student has met it. The Law of Large Numbers says that if each agent’s behaviour is an independent draw from a common distribution with mean \mu, the average across many agents settles on \mu. The Central Limit Theorem adds that, given a finite variance, the shape of that average’s distribution is Normal, whatever the individual distribution looked like (Miller and Page 2007). That fits their working definition of emergence exactly: a well-defined aggregate that arises from individual behaviour and does not depend on the details of that behaviour.

Following Warren Weaver (1958, as reported in Miller and Page (2007)), they call this disorganised complexity. Agents’ quirks cancel out: an unusually high value here is offset by an unusually low one there. You cannot predict where one raindrop on a roof will fall into the gutter, but you can predict the flow at each point of the gutter in a storm (Miller and Page 2007). Without such averaging, they note (following Coates), roads, shops, insurers and telephone systems would all be swamped or deserted at random (Miller and Page 2007).

The hard cases are the others. A face made of black and white pixels survives a few flipped pixels, even a recolouring or an outline drawing, because what matters is the relationship between parts. Scramble enough pixels and it decays into static, and theorems about the average shade of grey say nothing about how a face arises (Miller and Page 2007). This is organised complexity: interactions that reinforce rather than cancel. It is where power-law avalanches, crashes, riots and traffic jams live, outcomes that are “decidedly not normal” (Miller and Page 2007).

Three worlds with the same 100 people make the contrast concrete (Miller and Page 2007):

  1. Independent shoppers. Each picks one of two identical grocery stores by a coin flip. Store attendance is approximately Normal, mean 50, standard deviation 5; more than 60 customers turn up only about 2% of the time.
  2. Crowd-avoiders (negative feedback). Shoppers dislike crowds, and one shopper a period may switch to the emptier store. Attendance locks at exactly 50 and returns there after small shocks: a degenerate distribution, more predictable than chance.
  3. A bank that can fail (positive feedback). Each person withdraws with probability ½, and the bank holds reserves for 60. Below 60 the distribution looks just like world 1, but in the roughly 2% of days that cross 60 the bank fails, panic follows, and all the remaining probability is pushed into a fat upper tail.

Miller and Page’s sharpest remark is that most social-science theory studies worlds 1 and 2: independence, or negative feedback that delivers a stable equilibrium (Miller and Page 2007). World 3 is where the large events are. And many systems mix both kinds of feedback. In Conway’s Game of Life a moderate number of live neighbours begets life while too few or too many kill it, and the result is coherent moving structures (gliders) that can be tracked without reference to the rules underneath (Miller and Page 2007). (Turing’s activator–inhibitor patterns are the same mixture in continuous space: short-range reinforcement, long-range suppression.)

The lesson for social science

Schelling crystallises the danger emergence poses to naïve inference: the macro pattern is not the sum of the micro intentions. You cannot conclude from observed segregation that individuals are extremely prejudiced, nor design policy as if fixing preferences linearly fixes the outcome — the mapping from micromotives to macrobehaviour is nonlinear and emergent. This is the conceptual root of the ecological fallacy and of why agent-based models exist.

Common pitfalls

WarningWhere this goes wrong
  • Reading intentions off outcomes. Stark segregation does not imply extreme preferences (Schelling); the aggregate can betray the individuals. (Miller and Page 2007)
  • Assuming the representative agent. Averaging individuals away erases exactly the heterogeneity and interaction that generate the emergent pattern. (Miller and Page 2007)
  • Expecting macro to track micro linearly. Small changes in local rules/thresholds can flip the global outcome (tipping). (Miller and Page 2007)
  • Treating tipping and segregation as one thing. A system can segregate almost completely with little cascading movement (40/40), or churn a great deal on the way to the same end state (30/50). Measure the process and the outcome separately. (Miller and Page 2007)
  • Treating a threshold as a continuous dial. With a handful of neighbours, shares come in steps, so “nearby” thresholds can behave very differently and distant ones identically. Check which discrete cases a parameter change actually affects, including what happens at exact equality. (Miller and Page 2007)
  • Trusting one geometry. Grid, loop and block networks with the same number of neighbours give different segregation and tipping. Report the network as a modelling choice, not a backdrop. (Miller and Page 2007)
  • Assuming the CLT world. Bell curves and standard errors presume agents whose quirks cancel. With positive feedback (runs, panics, cascades) the same 100 people can produce a fat tail beyond a threshold, and with negative feedback a near-certain outcome. Ask which kind of interaction you are modelling before reaching for Normal theory. (Miller and Page 2007)
  • “Emergence” as mysticism. It is not magic — it is the concrete, simulable consequence of local rules; if you can’t grow it, treat the claim with suspicion. (Mitchell 2009)

Appendix · the mathematics

Micromotives → macrobehaviour. Let \tau be each agent’s tolerance threshold (minimum same-type fraction). For small \tau a fully mixed configuration is unstable: any local fluctuation that raises one type’s local share makes the other type’s agents unhappy, they leave, raising the share further — a reinforcing loop that drives the neighbourhood to near-purity. The integrated state is a knife-edge; the segregated states are the stable attractors. The model has a tipping structure: above a critical \tau the mixed state can persist; below it, segregation is essentially inevitable — yet the critical \tau is far lower than intuition expects (≈ 1/3, not 1/2).

Why thresholds act in steps. An agent with n occupied neighbours, j of them its own type, moves under a threshold \theta when j/n<\theta. Two thresholds \theta_1<\theta_2 give different behaviour only for the configurations with \theta_1\le j/n<\theta_2. For n=2,\dots,8 there are \sum_{n=2}^{8}(n+1)=42 pairs (n,j), and for \theta_1=0.4,\ \theta_2=0.5 only 2/5 and 3/7 fall in the gap (Miller and Page 2007). A threshold is therefore really a choice of which of these finitely many fractions count as acceptable. Whether the inequality is strict decides what happens at shares exactly equal to \theta, such as j/n=1/2, and that one case can be the whole difference between two parameter settings.

Overlap. For a tie x–y, count the agents in both closed neighbourhoods (each agent together with its eight neighbours), then average over x’s eight ties. On a Loop with four neighbours a side, the neighbour at distance d shares 9-d agents, giving 2(8+7+6+5)/8=6.5. On the Grid an orthogonal neighbour’s 3\times3 block overlaps x’s in 6 cells and a diagonal one in 4, giving 5.0. In a Pack of eight, each of the seven pack-mate ties shares all eight pack members, and M&P score the one outside tie as sharing none, giving 7\cdot8/8=7.0 (Miller and Page 2007). (Strictly, the outside pair share at least themselves, which would give 7.25. The ordering Pack > Loop > Grid is the same either way.) Higher overlap means more neighbourhood redundancy: a departure is felt by many of the same agents at once.

Disorganised vs organised, in one line each. If agents’ choices X_1,\dots,X_n are independent with mean \mu and variance \sigma^2, the total S_n has \operatorname{sd}(S_n)=\sigma\sqrt n, so the share S_n/n has spread \sigma/\sqrt n\to0: the quirks cancel. For 100 coin-flipping shoppers, S_{100}\sim\text{Bin}(100,\tfrac12) with mean 50, SD 5 and P(S_{100}>60)\approx0.018 (Miller and Page 2007). Feedback breaks independence. Under crowd-avoidance each switch moves the count towards 50, so the distribution collapses to a point; with a run on the bank, any day that crosses 60 sends every remaining depositor to the counter, so the probability that would have thinned out above 60 is shifted to the right into a fat upper tail (Miller and Page 2007).

Why prediction is hard. Emergent outcomes are typically path-dependent (history matters) and computationally irreducible — for many systems there is no shortcut to the macro state except to run the micro dynamics, which is exactly why simulation/ABM is the native method.

::: {.lead-kernel}
A single ant is nearly mindless; an ant colony forages with collective intelligence. A neuron is not
conscious; a brain is. **Emergence** is this leap — macroscopic pattern and behaviour arising from many
simple parts following local rules, **not present in or predictable from any part**. Its social-science
emblem is **Schelling's segregation model**, where a *mild* individual preference produces *stark* collective
segregation that **no one intended** — the defining lesson of the whole Dynamics cluster.
:::

## Why it matters

Emergence is why social aggregates can't be read off individual intentions. Segregation without racists, bank
runs without panic, traffic jams without crashes, inequality without villainy — the macro pattern is
"disconnected from its origins" [@mitchell_complexity]. For a quantitative social scientist this is a
standing warning: the **representative-agent** shortcut and the assumption that group outcomes mirror
individual preferences can both be exactly wrong.

## Emergence: "more is different"

**Emergence** occurs when large numbers of simple entities — each following local rules with **no central
leader** — produce macroscopic patterns **not present in, or predictable from, the parts** [@mitchell_complexity;
@millerpage_cas]. The slogan is **"more is different"**: aggregate behaviour is *"disconnected from its
origins"* [@mitchell_complexity]. The canonical examples [@mitchell_complexity; @millerpage_cas]:

- **Ant colonies** — coherent foraging fronts from simple **chemical signals**, no commander.
- **Brains** — intelligence and consciousness from interactions of **non-conscious neurons**.
- **Markets** — global prices from the chaotic, heterogeneous efforts of independent traders. (Grown from
  the bottom up, such a price is a statistical cloud around equilibrium, not a single number: see
  [markets without an auctioneer](markets-without-an-auctioneer.qmd).)
- **Traffic jams & segregation** — collective patterns that appear even when **no individual intends them**.

## Self-organisation

**Self-organisation** is the dynamical process by which a system **spontaneously forms structure and order
over time without a central controller or blueprint** [@mitchell_complexity]. It is **"collective
intelligence" arising from local feedback** — fireflies flashing in unison, the mutually sustaining structure
of an economy [@mitchell_complexity]. (It is also Meadows' high
[leverage point](systems-traps-and-leverage-points.qmd): a system that can build its own structure can adapt
to almost anything.)

## Schelling: mild preferences, stark segregation

The classic social-science demonstration [@millerpage_cas]. Agents of two types sit on a grid and **move if
the fraction of same-type neighbours falls below a threshold**. The shock is how **little** intolerance it
takes: agents content to be a **minority** — happy with, say, just **a third** of neighbours like themselves
— still **unravel an integrated city into stark segregation** [@millerpage_cas]. It is the purest example of
an **"unintended collective outcome"**: local preferences no one would call extreme aggregate into a macro
pattern no individual sought [@millerpage_cas].

```{python}
#| label: fig-schelling
#| fig-cap: "Schelling's segregation model, simulated by hand. Two groups (black, grey) and empty cells (pale) start randomly mixed (left). Each agent is 'happy' only if at least 35% of its occupied neighbours are the same type; unhappy agents move to a random empty cell, repeated until everyone is content (right). The result: near-total segregation — even though every agent was willing to live in a neighbourhood that is 65% the *other* type. The segregation index (mean same-type-neighbour fraction) jumps from ~0.5 (random) to ~0.8+. No agent wanted this; the structure emerged from mild local preferences. That gap — between micromotives and macrobehaviour — is emergence."
#| code-fold: true
#| code-summary: "Show the figure code"

import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(2)
L, empty_frac, thresh = 50, 0.10, 0.35
cells = rng.choice([0, 1, 2], size=(L, L), p=[empty_frac, (1-empty_frac)/2, (1-empty_frac)/2])
grid0 = cells.copy()

def same_frac(g, i, j):
    t = g[i, j]
    if t == 0: return 1.0
    s = o = 0
    for di in (-1, 0, 1):
        for dj in (-1, 0, 1):
            if di == 0 and dj == 0: continue
            v = g[(i+di) % L, (j+dj) % L]
            if v != 0:
                o += 1; s += (v == t)
    return 1.0 if o == 0 else s/o

def seg_index(g):
    vals = [same_frac(g, i, j) for i in range(L) for j in range(L) if g[i, j] != 0]
    return np.mean(vals)

s0 = seg_index(cells)
for _ in range(40):
    moved = False
    empties = list(zip(*np.where(cells == 0)))
    order = rng.permutation(L*L)
    for idx in order:
        i, j = idx // L, idx % L
        if cells[i, j] != 0 and same_frac(cells, i, j) < thresh and empties:
            e = empties.pop(rng.integers(len(empties)))
            cells[e] = cells[i, j]; empties.append((i, j)); cells[i, j] = 0
            moved = True
    if not moved: break
s1 = seg_index(cells)

cmap = plt.matplotlib.colors.ListedColormap(["#f4f3ec", "#161613", "#8a8a7e"])
fig, (axL, axR) = plt.subplots(1, 2, figsize=(8.6, 4.4))
axL.imshow(grid0, cmap=cmap, vmin=0, vmax=2); axL.set_title(f"start: mixed (segregation {s0:.2f})"); axL.axis("off")
axR.imshow(cells, cmap=cmap, vmin=0, vmax=2); axR.set_title(f"end: segregated (segregation {s1:.2f})"); axR.axis("off")
fig.suptitle("Schelling: a 35% same-type preference produces near-total segregation", fontsize=11)
fig.tight_layout()
plt.show()
```

## Schelling up close: tipping is not segregation {#sec-tipping-vs-segregation}

Miller and Page rebuild Schelling's model in one dimension to take it apart, and the first thing they do is
separate two words that are usually run together [@millerpage_cas]:

- **Tipping** is a *process*: moves that trigger more moves. They measure it as the number of agents who
  eventually move relative to the number who wanted to move at the start.
- **Segregation** is an *outcome*: how rarely the two types end up side by side. They count adjacent pairs
  (ignoring empty sites) of different types; fewer means more segregated.

Their world is a ring of 100 sites, each equally likely to hold an agent of type A, an agent of type B, or
nobody. Each agent looks four sites each way and moves to a random empty site if too few of its neighbours
are its own type. Averaged over 500 runs [@millerpage_cas]:

| Thresholds (type A / type B) | 40 / 40 | 30 / 50 | 31 / 49 |
|---|---|---|---|
| Agents who initially want to move | 19.2 | 26.0 | 19.8 |
| Agents who move in the first round | 21.9 | 30.1 | 23.2 |
| Agents who move within 100 rounds | 42.5 | 110.8 | 58.8 |
| Mixed-type adjacencies at the end | 5.8 | 5.0 | 5.8 |

Three lessons come out of this one table.

**1. Little tipping can still mean a lot of segregation.** With symmetric 40% thresholds only about twice as
many agents move as wanted to at the start, yet mixed adjacencies fall from about 30 to 5.8. Making the
thresholds asymmetric (30/50, closer to Schelling's own set-up) roughly quadruples the movement but ends at
about the same level of segregation. The extra movement comes almost entirely from the less tolerant type: 23
of the 29 first-round movers. With only one type doing the sorting, getting to a segregated state takes
longer [@millerpage_cas]. Most of the cascades are "my neighbour left, so now I want to leave" rather than
"the newcomer drove me out" [@millerpage_cas].

**2. Thresholds act in steps, not smoothly.** An agent with eight neighbours can only see same-type shares of
0, 1/8, 2/8 and so on, so many different threshold values produce identical behaviour. Across neighbourhoods
of two to eight agents there are 42 possible same-type counts, and a 40% rule and a 50% rule disagree on only
two of them (2 of 5 and 3 of 7; our count confirms M&P's figure) [@millerpage_cas]. That is why 31/49, which
looks like a small change from 30/50, behaves like 40/40 instead.

::: {.callout-note title="Our replication, and a boundary the book leaves implicit"}
We rebuilt the model by hand (ring of 100, four neighbours each side, share of *occupied* neighbours,
location-ordered updating, 300 runs). The 40/40 column reproduces closely under the rule as stated, "move if
the share is *below* the threshold": 19.3 / 22.0 / 42.3 / 5.5 against the book's 19.2 / 21.9 / 42.5 / 5.8.
Under that strict rule, though, 30/50 and 31/49 would be **identical**, because no attainable share lies in
$[0.30, 0.31)$ or $[0.49, 0.50)$. The book's two asymmetric columns are reproduced only when agents also move
at a share *exactly equal* to their threshold: we then get 25.9 / 29.5 / 138.7 / 5.1 for 30/50 and
19.8 / 22.9 / 59.0 / 5.4 for 31/49. On that reading, the whole difference between the two asymmetric columns
is whether a 50% agent with exactly half same-type neighbours stays or goes. That supports M&P's point about
steps, and adds that *which side of the boundary "exactly half" falls on* can be the entire result.
:::

**3. The thresholds that drive tipping are the ones at 50%.** High tipping goes with the 50% rule. Moves are
positive feedback, and under the right conditions that feedback produces cascades that sweep the system
[@millerpage_cas].

## Does the grid matter? Schelling on networks {#sec-schelling-networks}

Schelling used a checkerboard. Is the result an artefact of that geometry? Miller and Page rerun it on three
networks in which every agent has eight neighbours [@millerpage_cas]. **Loop**: houses round a lake, four
each side. **Grid**: Schelling's eight surrounding squares. **Pack**: city blocks of eight in which even
physically adjacent houses can belong to "different" neighbourhoods. Each network had 400 agents, half the
sites occupied, a 40% threshold, and 500 trials:

| | Grid | Loop | Pack |
|---|---|---|---|
| Segregation (mean share of like-type neighbours at rest) | 75% | 78% | 80% |
| Tipping (share of relocations set off by the initial moves) | 14% | 20% | 31% |

The grid **understates** segregation; it is the least segregating of the three. The ordering follows
**overlap**, the average number of neighbours an agent shares with each of its neighbours. On M&P's count it
is 7.0 for the Pack, 6.5 for the Loop and 5.0 for the Grid. The more your neighbours are also each other's
neighbours, the more one departure unsettles the rest, so moves trigger further moves and like types gather
together [@millerpage_cas]. The same overlap measure ordered conformity under [majority
rule](dynamics-on-networks.qmd#sec-majority-rule). Miller and Page's conclusion applies to both: in a
"pinhead world" with no network, there is no segregation and majority rule gives total conformity. These
results are easy to derive and tell you nothing [@millerpage_cas].

## Two kinds of emergence: disorganised and organised complexity {#sec-organised-complexity}

Miller and Page start their chapter on emergence with a warning and a theorem [@millerpage_cas]. The
warning: much of the *feeling* of emergence is surprise, and surprise is close to ignorance. Planetary
motion looked mysterious until Kepler showed it was an ellipse. The theorem: we already have a rigorous
result about emergence, and every statistics student has met it. The
[Law of Large Numbers](../01-foundations/law-of-large-numbers.qmd) says that if each agent's behaviour is
an independent draw from a common distribution with mean $\mu$, the average across many agents settles
on $\mu$. The [Central Limit Theorem](../02-inference/sampling-distributions-clt.qmd) adds that, given a
finite variance, the *shape* of that average's distribution is Normal, whatever the individual
distribution looked like [@millerpage_cas]. That fits their working definition of emergence exactly: a
well-defined aggregate that arises from individual behaviour and **does not depend on the details** of
that behaviour.

Following Warren Weaver (1958, as reported in @millerpage_cas), they call this **disorganised
complexity**. Agents' quirks cancel out: an unusually high value here is offset by an unusually low one
there. You cannot predict where one raindrop on a roof will fall into the gutter, but you can predict the
flow at each point of the gutter in a storm [@millerpage_cas]. Without such averaging, they note
(following Coates), roads, shops, insurers and telephone systems would all be swamped or deserted at
random [@millerpage_cas].

The hard cases are the others. A face made of black and white pixels survives a few flipped pixels, even
a recolouring or an outline drawing, because what matters is the *relationship* between parts. Scramble
enough pixels and it decays into static, and theorems about the average shade of grey say nothing about
how a face arises [@millerpage_cas]. This is **organised complexity**: interactions that **reinforce**
rather than cancel. It is where power-law avalanches, crashes, riots and traffic jams live, outcomes
that are "decidedly not normal" [@millerpage_cas].

**Three worlds with the same 100 people** make the contrast concrete [@millerpage_cas]:

1. **Independent shoppers.** Each picks one of two identical grocery stores by a coin flip. Store
   attendance is approximately Normal, mean 50, standard deviation 5; more than 60 customers turn up only
   about 2% of the time.
2. **Crowd-avoiders (negative feedback).** Shoppers dislike crowds, and one shopper a period may switch
   to the emptier store. Attendance locks at exactly 50 and returns there after small shocks: a degenerate
   distribution, *more* predictable than chance.
3. **A bank that can fail (positive feedback).** Each person withdraws with probability ½, and the bank
   holds reserves for 60. Below 60 the distribution looks just like world 1, but in the roughly 2% of days
   that cross 60 the bank fails, panic follows, and all the remaining probability is pushed into a
   **fat upper tail**.

Miller and Page's sharpest remark is that most social-science theory studies worlds 1 and 2:
independence, or negative feedback that delivers a stable equilibrium [@millerpage_cas]. World 3 is
where the large events are. And many systems mix both kinds of feedback. In Conway's
[Game of Life](cellular-automata.qmd) a moderate number of live neighbours begets life while too few or
too many kill it, and the result is coherent moving structures (gliders) that can be tracked without
reference to the rules underneath [@millerpage_cas]. (Turing's
[activator–inhibitor patterns](pattern-formation-and-reaction-diffusion.qmd#sec-turing) are the same
mixture in continuous space: short-range reinforcement, long-range suppression.)

## The lesson for social science

Schelling crystallises the danger emergence poses to naïve inference: **the macro pattern is not the sum of
the micro intentions**. You cannot conclude from observed segregation that individuals are extremely
prejudiced, nor design policy as if fixing preferences linearly fixes the outcome — the mapping from
micromotives to macrobehaviour is **nonlinear and emergent**. This is the conceptual root of the
[ecological fallacy](../00-overture/using-existing-data.qmd) and of why
[agent-based models](agent-based-modelling.qmd) exist.

## Common pitfalls

::: {.callout-warning title="Where this goes wrong"}
- **Reading intentions off outcomes.** Stark segregation does not imply extreme preferences (Schelling); the
  aggregate can betray the individuals. [@millerpage_cas]
- **Assuming the representative agent.** Averaging individuals away erases exactly the heterogeneity and
  interaction that generate the emergent pattern. [@millerpage_cas]
- **Expecting macro to track micro linearly.** Small changes in local rules/thresholds can flip the global
  outcome (tipping). [@millerpage_cas]
- **Treating tipping and segregation as one thing.** A system can segregate almost completely with little
  cascading movement (40/40), or churn a great deal on the way to the same end state (30/50). Measure the
  process and the outcome separately. [@millerpage_cas]
- **Treating a threshold as a continuous dial.** With a handful of neighbours, shares come in steps, so
  "nearby" thresholds can behave very differently and distant ones identically. Check which discrete cases a
  parameter change actually affects, including what happens at exact equality. [@millerpage_cas]
- **Trusting one geometry.** Grid, loop and block networks with the same number of neighbours give
  different segregation and tipping. Report the network as a modelling choice, not a backdrop.
  [@millerpage_cas]
- **Assuming the CLT world.** Bell curves and standard errors presume agents whose quirks cancel. With
  positive feedback (runs, panics, cascades) the same 100 people can produce a fat tail beyond a
  threshold, and with negative feedback a near-certain outcome. Ask which kind of interaction you are
  modelling before reaching for Normal theory. [@millerpage_cas]
- **"Emergence" as mysticism.** It is not magic — it is the concrete, simulable consequence of local rules;
  if you can't grow it, treat the claim with suspicion. [@mitchell_complexity]
:::

## Appendix · the mathematics {.unnumbered}

::: {.math-appendix}

**Micromotives → macrobehaviour.** Let $\tau$ be each agent's tolerance threshold (minimum same-type
fraction). For small $\tau$ a fully mixed configuration is *unstable*: any local fluctuation that raises one
type's local share makes the other type's agents unhappy, they leave, raising the share further — a
**reinforcing loop** that drives the neighbourhood to near-purity. The integrated state is a knife-edge; the
segregated states are the stable attractors. The model has a **tipping** structure: above a critical $\tau$
the mixed state can persist; below it, segregation is essentially inevitable — yet the critical $\tau$ is
far *lower* than intuition expects (≈ 1/3, not 1/2).

**Why thresholds act in steps.** An agent with $n$ occupied neighbours, $j$ of them its own type, moves
under a threshold $\theta$ when $j/n<\theta$. Two thresholds $\theta_1<\theta_2$ give different behaviour
only for the configurations with $\theta_1\le j/n<\theta_2$. For $n=2,\dots,8$ there are
$\sum_{n=2}^{8}(n+1)=42$ pairs $(n,j)$, and for $\theta_1=0.4,\ \theta_2=0.5$ only $2/5$ and $3/7$ fall
in the gap [@millerpage_cas]. A threshold is therefore really a choice of *which* of these finitely many
fractions count as acceptable. Whether the inequality is strict decides what happens at shares exactly equal
to $\theta$, such as $j/n=1/2$, and that one case can be the whole difference between two parameter settings.

**Overlap.** For a tie $x$–$y$, count the agents in both *closed* neighbourhoods (each agent together with
its eight neighbours), then average over $x$'s eight ties. On a Loop with four neighbours a side, the
neighbour at distance $d$ shares $9-d$ agents, giving $2(8+7+6+5)/8=6.5$. On the Grid an orthogonal
neighbour's $3\times3$ block overlaps $x$'s in 6 cells and a diagonal one in 4, giving $5.0$. In a Pack of
eight, each of the seven pack-mate ties shares all eight pack members, and M&P score the one outside tie as
sharing none, giving $7\cdot8/8=7.0$ [@millerpage_cas]. (Strictly, the outside pair share at least
themselves, which would give $7.25$. The ordering Pack > Loop > Grid is the same either way.) Higher overlap
means more neighbourhood *redundancy*: a departure is felt by many of the same agents at once.

**Disorganised vs organised, in one line each.** If agents' choices $X_1,\dots,X_n$ are independent
with mean $\mu$ and variance $\sigma^2$, the total $S_n$ has $\operatorname{sd}(S_n)=\sigma\sqrt n$, so the
share $S_n/n$ has spread $\sigma/\sqrt n\to0$: the quirks cancel. For 100 coin-flipping shoppers,
$S_{100}\sim\text{Bin}(100,\tfrac12)$ with mean 50, SD 5 and $P(S_{100}>60)\approx0.018$
[@millerpage_cas]. Feedback breaks independence. Under crowd-avoidance each switch moves the count towards
50, so the distribution collapses to a point; with a run on the bank, any day that crosses 60 sends every
remaining depositor to the counter, so the probability that would have
thinned out above 60 is shifted to the right into a fat upper tail [@millerpage_cas].

**Why prediction is hard.** Emergent outcomes are typically **path-dependent** (history matters) and
**computationally irreducible** — for many systems there is no shortcut to the macro state except to *run*
the micro dynamics, which is exactly why [simulation/ABM](agent-based-modelling.qmd) is the native method.

:::
